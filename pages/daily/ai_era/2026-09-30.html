2. 突发，OpenAI 24小时在线dots正式上岗！GPT悍然推出500美元最贵套餐

09-30 06:17 原文链接

新智元报道

旧金山Fort Mason会场，OpenAI开发者大会燃爆了！
就在刚刚，奥特曼走上DevDay舞台，整整一个小时，一口气扔出了20大发布。

一个全新物种dots，7x24h在线的AI，正式诞生了。
不同与ChatGPT，它是OpenAI首个有独立云端电脑，随时随地替人类跑代码、盯项目的「常驻Agent」。

更震撼的是，奥特曼又祭出了下一代旗舰GPT-6.1 Sol，Astra级顶尖推理与代码能力，价格直接砍掉80%。
极速模式Ultrafast一同上线，300 tokens/s恐怖生成速度，是标准版的8倍。

现场，奥特曼重开200美金Pro订阅，并首次扔出「贵族套餐」——Pro 500。
使用量是ChatGPT Plus的25倍，可以访问Ultrafast模式，无5小时限制。

除此之外，大会上，OpenAI还发布了ChatGPT Space、Agents API、Codex云端版....信息量大到让人喘不过气。
最后的最后，「义父」Tibo拿个重置按钮，在现场为所有人来了一键重开。

有网友辣评，整场发布会中，最精彩的就是这个环节了。


dots来了OpenAI首个7x24h永在线AI
这次发布会最大的主角，叫dots。
它可不是OpenAI又一个聊天机器人，甚至不是ChatGPT的一个新增功能。

正如此前爆料，dots是一个全天候7x24h在线的Agent，由GPT-6 Astra加持。
它不仅有自己的云端电脑和浏览器，还天然打通超4000+工具升天，直接进驻Slack和Teams。
给它一个目标，它就自己去干，不需要你一步一步教。关闭屏幕，dots依然在后台24小时默默跑任务。
不用登录ChatGPT，dots就可以随时随地，为你开干。
第一次见面的流程还挺有仪式感。
打开ChatGPT，你的dot会先打个招呼，「嗨，我是你的dot，刚来ChatGPT报到，以后找上门的事都交给我。」

现场，OpenAI研究员给它起了个名字叫Alfred。
从被激活的那一秒起，Alfred就全面接管了后台所有的碎片化事务——
  • 自动化建站与上线

根据已审核的设计稿，Alfred在后台独立推进网站更新，遇到需要人类决策的地方（比如替换第一张和第三张配图）才会主动弹窗提醒，确认后立刻完成发布上线。
  • 跨平台数据追踪与董事会报告

它自主监控Teams中的用户反馈数据，直接同步更新待汇报的董事会PPT，甚至精准抓取核心指标——
产品易用性攀升，年营收同比增长51%。
  • 长程工程重构

从Google Meet的会议纪要中捕捉到「App需要迁移」的信息，自动排查流程并起草架构图。

还有一个来自OpenAI内部真实案例：一位员工忘了给一家出版机构开发票，他的Dot发现之后，自动准备好发票，发了个消息问他，「要发出去吗」？
他点了确认，事情就办完了。
这就是Dots的底层逻辑转变：它不是工具，它是同事。
你雇了一个永远不会请假、永远不会忘事、24小时都在线的数字员工。
而且它会越用越懂你——你的偏好、你的标准、你心目中「好」是什么样，它都在学。

当然，奥特曼也没有回避安全问题。每个Dot运行在独立的云端电脑上，个人电脑和数据默认隔离。它使用已保存的密码时不会把密码暴露给模型。
当它不在执行任务时，只会用只读权限在后台「主动研究」，不会发送消息或修改任何内容。
奥特曼在台上说了一句话，值得细品，「你不是在用一个工具，你是在建立一个团队」。
今天起，Pro、Business Premium和Enterprise用户可以创建自己的第一个Dot，对话不占用ChatGPT使用额度。

ChatGPT Space，工作流全被重构
如果说Dots是你的数字员工，那ChatGPT Space就是给这些员工和人类同事准备的办公室。
这个发布很有意思。过去一年，所有硅谷巨头都在往文档里塞AI——Google Docs加AI，Notion加AI，微软Office加Copilot。
但OpenAI反过来了：它直接造了一个「AI原生」的协作空间。

在Space里，你可以和同事、和各自的Dot在同一个页面上协作。
你可以在页面里写计划、做研究、生成图表、做数据分析。
你可以把Dot拉进来，像@一个同事一样问它：「帮我把这个变成柱状图」。图表立刻生成，还能实时筛选和查看数据点。
更关键的是，Space让Dot的工作不再是「藏在某个人的聊天记录里」。团队所有人和所有Dot共享同一个知识库，项目上下文不会因为换了个人就断了。
用奥特曼的原话说，「你在Space里的页面和文件都在一起，就像一个网盘。但Space是活的」。

GPT-6.1 Sol震撼登场Astra级智能，1/5价格
原本，大家对DevDay发布新模型，没有抱太大期待。
结果实在令人意外，奥特曼直接扔出了下一代旗舰GPT-6.1 Sol，现场掌声雷动。

这是继GPT-6 Sol发布不过一周后，OpenAI又一次重大发布。
GPT-6.1 Sol是一款超强模型，在软件工程DeepSWE v1.1测试中，性能直接追平了Astra。
而且，在长程业务自动化评测AutomationBench与科学推理Terminal-Bench Science上，直接干翻了Opus 5.5。
在操作电脑完成长流程任务（OSWorld 2.0）中，6.1 Sol离Astra只差2.1个百分点，成本约七分之一。


在价格方面，GPT-6.1 Sol再次踢碎门槛。
输入每百万token 2美元，输出10美元。对比Astra的10美元和50美元，仅为五分之一。
更夸张的是上下文缓存，每百万token仅需0.10美元，相比标准输入折扣高达95%。

现场，奥特曼还推出了Ultrafast推理模式，速度达到标准模式的8倍，大约每秒300个token。
现场演示中，同一个「造火箭」的任务，Ultrafast那边的火箭已经发射了，标准模式那边还没拼完模型。

目前，Ultrafast初期仅支持Astra，后续会开放给Sol。

为了匹配如此恐怖的调用频次，此前暂停的Pro 200会员全面重启。
不仅如此，OpenAI进一步加推Pro 500档位，25倍Plus的调用额度与Ultrafast的原生使用权，彻底解开生产力上限。


Codex搬上云写代码不用守着电脑
DevDay毕竟是开发者的主场，Codex这条线也没闲着。
最大的变化是，Codex整个搬上了云。
开发环境可以提前配好、反复复用，权限设一次就够。你人在外面，拿手机就能遥控它接着干。

命令行版Codex CLI也改了版，可以直接张嘴用语音下指令、中途改方向。
新增的/agents视图能同时盯住好几个子任务，长时间开着也不会乱成一团。

ChatGPT桌面端多了代码审查。
你离开电脑那会儿，它会自动把改动审一遍，审查意见能直接推回GitHub或GitLab。

Codex Security Cloud则专门抓安全漏洞。
它能扫整个GitHub仓库，每来一次新提交就审一次，自己排查、去重，再把修复方案准备好等你过目，背后默认接入的是OpenAI的网络安全专用模型。

API这边动静也不小。
驱动dots的那套底层技术，被直接打包成了Agents API。
电脑操作、多智能体协作、工具搜索、上下文压缩，开发者都能直接调用，相当于自己也能搭一个dots出来。

另一个新接口Decisions API，专门处理「从几个固定选项里快速挑一个」这类决策，比如一封邮件该归到哪类，智能体下一步该点哪个按钮。
提前试用的编辑拿它跑了一遍电脑操作回放，78次选择对了76次，响应只要230毫秒。
不过在另一组对话分类测试里，它和对手模型准确率打平，速度反倒慢了一截。
Tibo还晒了一组数。OpenAI核心接口Responses API的token流量，比去年今天涨了100倍，可用性还稳在99.9%。

个人智能体大战OpenAI亮出全部底牌
今晚这20多项发布，单拎出来看，每一项都能单独写一篇。
连起来看，OpenAI其实只干了一件事，就是把ChatGPT从一个你去问问题的地方，改造成一个替你干活的地方。
便宜的Sol让智能敞开了用，dots把活接了过去，Space和Pages给它们安排好了工位，插件又把外面的应用一个个接了进来，用户的订阅额度甚至能带到Notion和Devin里去花。
之所以这么急，是因为对手已经冲到了前面。

Meta的Muse上线三周，下载量就超过了300万，免费就能用，只是每周有额度上限，最近还在往小企业场景猛扩。谷歌的Spark早就在云端7×24小时替用户打工，SpaceXAI也推出了Grok Bot。
个人智能体，已经成了每家巨头都要抢的下一个入口。
dots的特别之处在于它的工作方式：你还没开口，它已经把结果放在你面前。它不问「需要我做什么」，它直接说「我做好了」。
奥特曼在演讲最后说，「有人把AI比作新的工业革命。我不太喜欢这个比喻。如果做对了，这更像一场新的文艺复兴」。

文艺复兴的核心，是让人有更多时间去做创造性的、有意义的事。
如果dots真的能帮你处理掉那些无聊、重复、消耗注意力的琐事——你打算用省下来的时间做什么？
这场发布会释放了一个清晰的信号：AI正在从「工具」变成「同事」，从「你用它」变成「它替你」。
转变已经发生。从今天开始。
你的dots，已经在等你了。

新智元报道

就在刚刚，GPT-6.1 Sol突袭上线！

现在，Codex里已经可用了。

在OpenAI开发者大会上，GPT-6.1 Sol就这么水灵灵地被发布了。

有趣的是，据说，因为对齐回归的问题，原定的GPT-6.1被紧急暂停。

但谁也没想到，OpenAI反手掏出了一个「干活特化版」的 GPT-6.1 Sol，直接杀进了 Codex 和 ChatGPT Work。

官方给出的口号非常诱人：“以五分之一的价格，获得接近 Astra 的智能水平。」

性能逼近地表最强GPT-6 Astra，但价格大缩水？

听起来，跟昨天发布的Sonnet 5.5异曲同工了。

看来，ASI双雄都在力押同一赛道——对整个AI应用层、尤其是Agent赛道发起降维打击。

有人评论：6.1 Sol 在基准测试上和 Astra 一样好，而且便宜 5 倍！OpenAI 在不到一周的时间里彻底杀回来了

价格打穿底线，Agent 终于用得起了！

GPT-6.1 Sol的价格，首先就非常惊喜。

它的API标准价定格在：

输入： 2美元 / 每百万 Token

输出： 10美元 / 每百万 Token

作为对比，GPT-6 Astra 的价格是输入 10美元、输出 50美元。也就是说，GPT-6.1 Sol 刚好是 Astra 价格的 20%。

不过，最让开发者们惊喜的，是它的「缓存读取价格」。

缓存输入： 仅仅 0.10美元 / 每百万 Token！

缓存写入： 2.50美元 / 每百万 Token

0.1美元的缓存读取价，比标准输入直接便宜了 95%！因此，用它运行Computer Use、代码生成 Agent时，价格简直跌穿地心。

官方纸面数据：「小杯」的价格，「超大杯」的表现

上周才发布的 GPT-6 Sol 因为表现不佳被不少人吐槽，今天OpenAI用 GPT-6.1 Sol 算是狠狠地挽回了颜面。

在编程能力（DeepSWE v1.1）上：它以五分之一的成本打平旗舰 Astra，比旧版 6 Sol 提高了 6.4个百分点。

在电脑操作（OSWorld 2.0）上，距离王者 Astra 仅仅相差 2.1分，单任务成本约为其七分之一。

在专业办公（AutomationBench）上，中等推理强度下，它得分比Opus 5.5 高出 2.2 个百分点，成本只有其三分之一！


复杂的专业 PDF 文档处理GDP.pdf 上，在所测试的各档推理设置下，GPT‑6.1 Sol 的得分均高于带回退机制的 Opus 5.5，而单任务成本不到其一半。它还以约五分之一的单任务成本，接近 GPT‑6 Astra 的性能。

在科学研究（Terminal-Bench Science）上，它的得分是旧版的两倍，单任务成本仅为 $5.47，而 Astra 和 Opus 5.5 都要 23美元以上，性价比简直爆炸。

在内部对齐评估中，GPT-6.1 Sol相较GPT-6 Sol改进重大，更接近GPT-6 Astra。

它在自身局限性方面更加透明，在尊重用户意图和安全约束方面也更加可靠。

官方系统卡泄露：实锤「最强循环模型」

与此同时， 45 页 GPT-6.1 Sol 系统卡也曝光了，其中有不少亮点。

在系统卡的第 8 节「可监控性」中，OpenAI 官方披露了一组惊人数据。

测试显示：与 6-Sol 和 5.6 Sol 相比，GPT-6.1-Sol 的思维链可控性强得离谱！

数据指出，在生成 750 到 1250 个 Token 长度的思维链时，GPT-6.1 Sol 能够成功遵循格式和控制指令的比例高达 44.8%，而上一代的 GPT-5.6 Sol 只有可怜的 16.1%。GPT-6.1 Sol 能够完美在大小写字母间交替输出，而不去破坏底层的逻辑链条。

大V@scaling01 在看到这份系统卡后，直接惊呼：

GPT-6.1-Sol 拥有极其疯狂的思维链可控性……这基本证实了它就是他们那个更小的循环模型！

什么是循环模型？


这意味着它不是为了像聊天机器人那样「一问一答」而设计的，它是专门为了在后台自我反思、自我纠错、不断循环思考而生的。

极高的思维链可控性，加上白菜价的上下文缓存费，GPT-6.1 Sol 天生就是为了跑大批量、长时间 Agent工作流而完美打造。

此外，系统卡还披露了其在网络安全上的恐怖实力。

GPT-6.1 Sol 被 OpenAI 内部评定为「Critical（危急）」级别。

在内部零日漏洞开发测试（Internal Port）中，它的任意代码执行成功率达到 21.5%，直接碾压了 GPT-6 Sol 的 5.5%，仅次于最强王者 Astra（31.5%）。

全网极限实测GPT-6.1 Sol

现在，X上已经被GPT-6.1 Sol的实测刷屏了。

看起来，有着神级性价比的6.1 Sol，简直赢麻了。

大V Bindu Reddy这样评价：「GPT-6.1-Sol 漂亮地转移了『智能 vs 成本』的前沿阵地。如果你在乎『每美元能买到多少智能』，6.1 Sol 绝对值得一看；如果你只想要无视成本的最高智商，Opus 5.5 依然领先。」

⚔️ 第二回合：逻辑、跑分与 CoT 控制力

@AiBattle_ 与 @LuminaBench 的跑分对决

在知名的 AA Intelligence Index 测试中，GPT-6.1 Sol (Medium档) 拿到了 48 分，直接追平了上一代 GPT-6-Sol 的 Max 档。

而 GPT-6.1 Sol (Max档) 拿到了 52 分，距离老大哥 Astra (Max档) 的 53 分，仅差 1 分！

LuminaBench 测试了 3D Colosseum 提示词（与 Gemini 4 Pro 对比），表示：「Astra 和新的 Sol 感觉简直一模一样，但它们依然被 Anthropic 的 Opus 和 Sonnet 碾压，如果下周 Haiku 超过它我都不意外。」

@kickingkeys 的 JS 视频生成他对比了 GPT-6.1 Sol 与 GPT-Astra 使用 JavaScript 创建视频的能力，从他放出的示例来看，两者在代码执行和最终效果上几乎不相上下。

所以，该如何定位GPT-6.1 Sol？

透露了 OpenAI 一个极其核心的战略转变：从「先发最强」变成了「先发最能干活」。

原定的 GPT-6.1 因对齐问题被按下，但 OpenAI 立刻把 Sol 版抢先塞进了 Codex 和 ChatGPT Work。注意！它目前只对 Plus 及以上付费用户开放，普通 Chat 里根本用不了！

正如网友 @TokenGremlin所总结：「GPT-6.1 Sol 基本上就是穷人版的 Astra。好好享受吧。说实话，这个版本出人意料地好。我真的很喜欢它，而且他们能把成本压到这么低，同时智能水平又如此接近 Astra，这确实让我印象深刻。」

即日起，所有 Plus、Pro、Business、Enterprise 和 Edu 用户均可在 ChatGPT 工作区和 Codex 中使用。开发者可以通过 API 调用 gpt-6.1-sol。同时，OpenAI 还推出了最高提速 8 倍的 Ultrafast 版本，专供高阶开发者。

在前端和画图上，GPT-6.1 Sol 暂时打不过Sonnet 5.5 和 Opus 5.5，但在企业最在乎的「多步骤逻辑」、「大规模代码Agent」和「成本控制」上，它直接掀翻了桌子。
