9. 群星闪耀时：OpenAI公开的722篇稿件，背后的科学家群像

10-14 19:47 原文链接

新智元报道

OpenAI公开722篇由AI撰写的数学与理论计算机稿件之后，丹麦奥尔堡大学AI安全实验室Qiongxiu Li发起的开源项目On Whose Shoulders 《巨人之肩》，对这批AI稿件的全部相关文献开展了逐条核对与系统性溯源分析。

结果是：跨越5个多世纪，11,067部人类著作，约9,600位数学家，其中114位是菲尔兹奖、阿贝尔奖或沃尔夫奖得主。

这类工作常被写成「AI解决了某某难题」。

这句话其实只说了一半，另一半是：AI是基于什么工作解决的。

大多数作者不是历史书里的名字，而是今天仍活跃的数学与理论计算机科学家。

从原句看，AI稿件是把这些科学家成果当作工具来用的：

  • 在算术几何里，一篇稿件「由[Fargues–Scholze 2024]」把某些向量丛与p进局部系统对应起来，这是Laurent Fargues与舒尔茨的工作。

  • 在双有理几何里，有的稿件沿用Caucher Birkar与一位合作者近期的策略，有的应用Birkar关于有界补的定理；还有的建立在Osamu Fujino的归纳法，以及Omprokash Das、Christopher Hacon与Mihai Păun的工作之上。

  • 在概率论里，稿件依靠Hugo Duminil-Copin等人对随机簇模型的临界穿越估计，以及Bertrand Duplantier、Jason Miller与Scott Sheffield的「树的配对」（mating of trees）定理。

  • 一个图论反例用了洛瓦斯与Balázs Szegedy的图极限采样构造；一个组合反例沿用了布尔甘、Nets Katz与陶哲轩的和积方法。

  • 一篇关于自旋玻璃的稿件，用的是Michel Talagrand的空腔方法。

  • 一个Ricci流论证用了佩雷尔曼2002年的熵单调性；一个Hodge理论论证用了德利涅的半单性论证。

华人数学家在这场接力里：

  • 丘成桐1976年证明卡拉比猜想的工作，被10多篇稿件引用。

  • 陈省身1944年对高斯–博内公式的内蕴证明，以及他与James Simons 1974年提出的陈–西蒙斯形式，各被三篇工作用到；其中一篇写道「我们使用陈–西蒙斯超渡泛函」。还有两篇工作研究的仿射极大曲面问题，正是陈省身1979年提出的。

  • 在最近大热的调和分析里，OpenAI的四维Kakeya稿件正是建立在王虹与Joshua Zahl 2025年的三维Kakeya挂谷猜想的证明之上，证明中的Bourgain条件还引用了王虹、郭少明、张瑞祥2024年工作。在与之紧密相连的Bochner–Riesz问题上，用到了郭少明、Changkeun Oh、王虹、Shukun Wu、张瑞祥人2025年的工作和陶哲轩2003年的双线性限制估计，并列作为波包方法的出处。

  • 一篇关于丰度猜想的稿件，沿用了许晨阳与Lei Zhang的叶状结构判据。一篇关于硬球气体的稿件，引入了邓煜、Zaher Hani与Xiao Ma从粒子动力学推导Boltzmann方程的估计。

  • 田刚与John Morgan关于Ricci流与庞加莱猜想的专著，丁剑与Allan Sly、Nike Sun对可满足性猜想的证明，以及杨振宁与李政道、黄克孙1957年关于硬球玻色气体的论文，也都在参考文献之中...

上述情况也适用于其它科学发现。OpenAI的纳维-斯托克斯方程论文从欧拉于1757年提出的方程出发，然后回顾了Leray于1934年提出的弱解以及Caffarelli、Kohn和Nirenberg的部分正则性定理。谷歌AlphaFold基于结构生物学家数十年来逐一解析的蛋白质结构进行训练；其前提可以追溯到Anfinsen于1973年的发表，即蛋白质的序列决定了其形状。


工程师造出机器科学家给它可学的东西

对于一个做出科学突破的模型(GPT, Claude等)来说，工程师造出机器：架构、训练代码、数据管线、算力。科学家提供它可学习的高质量内容，也决定它朝哪里去。预训练。模型学的是根据前文预测下一个词。

有一篇AI稿件里写着：「由射影直线上向量丛的分裂定理，E是线丛的直和」。这个事实不是模型发现的。

1957年格罗滕迪克给出了它的经典形式，此后数学家在论文、教材和讲义里一遍遍写下这一步。

科学家的直觉，是知道下一步该用哪个引理；模型的直觉，是从人类写下的千千万万个「下一步」里估计出来的概率。监督微调。模型在一批精选的推理链上学习「怎样一步步解题」。这些推理链有的由人写成，有的由模型合成；但合成的也从人出的题目和指令出发，由人设计的检验决定去留。

最后强化学习和推理时采样，只能强化或找到模型本来就能采样到的东西

强化学习与推理时采样。模型对一道题尝试许多次，验证器留下做对的。这靠的是采样：如果模型几乎从不写出正确的证明，奖励全是零，就无从学起。

让「做对」从几乎没有变成偶尔出现的，很大程度上是此前训练数据的质量。简单地说：工程师让学习成为可能，而可学的内容，很大一部分来自不同领域科学家。


科学家提供了高质量的学习信号

预训练和监督微调，给了模型直觉和推理的方式，但前沿的新结果，靠的是大规模的采样：训练时的强化学习，推理时的搜索和agent。它们的共同点是，让模型对一个问题做许多次尝试（rollout），再由验证器决定哪些算数。

成功的轨迹，又可以成为下一轮的训练数据。但要让这种「尝试-验证」的循环真正转化为模型能力的提升，关键在于信号的质量。梯度决定模型从一个样本中学到什么，而它的好坏取决于背后的信号。

很大一部分强信号来自科学家：严谨的证明，让训练有清晰的下一步可学；挑选得当的题目，让奖励不至于全是零或全是一；精确的验证器，保证信号指向正确的方向。无论采样发生在训练时还是推理时，科学家都可以处在这个循环的三个位置上。

(1)挑选问题。训练在「刚好够得着」的问题上学得效率最高，推理时的算力也最值得花在这样的问题上。好的问题为下一轮模型训练留下好的种子，平庸的题目只留下平庸的种子。挑出这样的问题，则需要科学家所说的taste。比如，埃尔德什、丘成桐、希尔伯特的问题清单，做的正是这件事。

(2)定义什么算正确。训练时，验证器决定奖励；推理时，它决定许多次尝试里留下哪一个。验证标准写得松，模型训练就会钻空子。数学之所以最先能成为试验场，是因为数学家早已把「证明」定义得极为精确。

(3)评判结果。10月7日，OpenAI在发现一处符号错误后撤回了3篇稿件，并修订了另外14篇。他们的仓库说明也写道，部分未经形式化的结果「可能有问题」。哪些结果成立，哪些重要，哪些方向值得投入下一轮算力，这些判断仍是科学共同体的工作。

所以，AI再强大，也需要驾驶员。这好比开采石油：钻机再强，也要有地质学家决定在哪里下钻，判断打上来的是不是油。在下面这个循环里，科学家挑选问题、定义正确、评判结果；AI则以人无法企及的规模去尝试。

科学家退后一步梯度信号会变弱


假设科学家真的退后一步，会发生什么？

模型仍然会采样，仍然会尝试。但它会被指向越来越窄的问题，用越来越松的验证器筛选答案，用越来越单一的数据塑造自己的采样。没有好的仪器，采样就碰不到新的知识。更麻烦的是，在缺少外部检验的情况下，一个主要靠自己的输出喂养的模型会逐渐退化。

已有研究发现，模型如果反复用模型生成的数据训练，会丢失分布中稀少的部分，逐渐退化。新的问题、新的想法、新的实验数据，以及检验它们的仪器，今天仍然需要科学家的参与：提出问题，设计实验，判断结果。未来，一部分新数据可能来自AI与物理世界之间的闭环，比如自动化实验室；但做什么实验、测得准不准、结果意味着什么，仍然需要领域科学家参与。

所以，「AI都能解决，科学家不再被需要」这句话，不只是关于科学家的。它会影响社会的激励流向哪里，也会影响年轻人是否还愿意投身科学之中。这两件事最终都会回到模型身上：这样的人少了，新的问题就少了，验证器也少了，梯度信号自然就弱了。


最后

数千年来，人类是唯一从事科学研究的智慧生命，许多发现，都是科学家们毕生的努力的结果。

如今，超级智能正触及科学的前沿，它能证明的、能发现的、能预测的，只会越来越多。

但每一次突破，都建立在那些光芒之上：人类最高的智慧、最深的孤独、最漫长的努力。

科学家是连接人类知识与AI的桥梁。谨以此向人工智能时代的科学家们致敬——他们的名字，应当与建立在他们工作之上的成果连在一起。

8. 国产芯片大杀器！全栈开源，断网狂飙千亿模型

10-14 19:47 原文链接

新智元报道


一张96GB显存的专业卡卖13.8万元，一套128GB的DDR5内存逼近2.5万元。
连一向淡定的库克，都在财报会上把这轮内存暴涨形容成「百年一遇的洪水」。
离谱的是，硬件越贵，AI公司越往本地端猛砸。OpenAI刚被曝一口气买下数万台Mac，专门用来训练能自己操作电脑的Agent。
原因很简单，24小时连轴转的Agent如果全搁在云端跑，光Token费就能把账单烧穿，大模型往端边搬家已经是明牌。
但把芯片和内存买回来，只算交了半张门票。
要把大模型做成一台稳定好用的终端产品，模型适配、框架打通、性能调优，如果有现成的工具和经验，开发团队就不用样样从头摸索。
今天的生态合作伙伴大会上，后摩智能宣布，整套AI生态软件栈将全面开源！

从拿到模型到做成产品，整条工具链全部开源。到明年1月，15个开源项目会陆续上线。
M50芯片量产还不到一年，就已经有150多款终端产品定下要用它，合作客户破百，甚至把1220亿参数的大模型塞进了一个300克的小盒子。

这套软件栈，就是在这些项目里逐步开发、验证和完善的。

一整条AI落地流水线，全开源了
做一个离线会议助手，看起来只要三步：录音转文字、大模型写纪要，最后存进电脑。
真正动手，难题才冒出来：模型要塞进有限的内存，推理要适配芯片，语音识别和大模型还得协同运行。好不容易跑通，后面还有性能调优、稳定性测试和上线维护。
更麻烦的是，下一家团队做同类产品时，这些工作往往还要重来一遍。
后摩这次开源的工具链，一口气覆盖了从拿到模型到产品上架的全过程，一共分四层。
第一层是模型处理工具。

开发者拿到一个新模型，先用它做量化（把模型压小）、编译和精度评估，把它转换成芯片能跑的格式。
平时往端边设备里塞模型，往往得先把模型硬压成低精度格式，精度一掉，工程师又要花大把时间调优往回找补。
而M50原生支持浮点计算，开发者完全可以按需求直接用浮点格式部署，从源头上少掉一层折腾。
第二层是推理框架、算子库和运行时。
这一层相当于芯片上的总调度，负责把计算任务精准派发下去，并针对M50的存算一体架构做贴身优化。

模型跑得快不快、占多少内存、功耗能不能压住，全看这一层的调度功力。

第三层是领域套件、模型流水框架和中间件。
它负责让多个模型像交响乐团一样配合干活。还是说那个会议助手，语音转文字、文字转纪要、纪要存进应用，中间的每一次交接，都靠这一层来丝滑搞定。
第四层是部署运维工具。
产品交付之后，后续的升级、监控、大批设备的管理，全归它管。
这些硬核工具，后摩准备分三批开源。
第一批是对llama.cpp、vLLM的适配版，这俩可是开发者圈子里最常用的开源推理框架。大家不用换习惯，用着最顺手的工作流，就能接入后摩芯片。
第二批是后摩自研的推理框架，针对自家芯片做深度优化，性能能发挥得更足。
第三批是中间件和各类工具，帮你把一堆散装模型的能力，串成一个能卖钱的产品。
整个开源清单里，ModelZoo（模型示例库）、推理引擎、领域套件一应俱全。连用来管理大批加速卡的Kubernetes基础设施和NPU卡集群管理平台，也一并放了进来。
现在去GitHub搜houmo-ai，已经能看到postmo-modelzoo、postmo-quantflow、vllm-postmo，以及llama.cpp、vLLM的适配版本了。

拿已经公开的postmo-modelzoo来说，它就像一份开箱即用的「实战样板间」。
从量化编译、性能评估到最终部署，每一步都有现成的代码和工具可以直接对照上手，推理示例横跨Linux、Windows 11和Android三大平台。
光是模型目录就一口气列了15个大类，语音识别、语音合成、大语言模型、视觉语言模型、图像生成、全模态全在里面。
用后摩自己的话说，这次开源就是要做到「最佳实践共享无保留」。

150多款产品，押注同一颗芯片
150多款产品押注同一颗M50，意味着这颗芯片要同时闯过Agent Computer、智能移动终端、具身机器人和边缘推理四道截然不同的关卡。
有的设备极其挑剔功耗，有的连网线都不让插，还有的必须跑在纯血国产系统上。

Agent Computer：300克的盒子，跑1220亿参数
Agent Computer，简单说就是专门用来跑AI Agent的电脑。最具代表性的，就是联想的AI主机P7。
这台主机只有300克，一只手就能托住。整机最大功耗30W，插个充电宝就能带走。
就算拔掉网线，也能在本地跑1220亿参数的大模型！每秒输出50个Token，上下文最长支持128K。
它搭载的是后摩M50芯片。典型功耗为10W，可提供160TOPS的INT8算力，最高支持48GB LPDDR5/5X内存。
Agent可能需要7×24小时运行，还会持续处理邮件和私人文件。
如果放在云端跑，每个月要交一大笔Token费，数据交出去也不放心。
换成P7，一次性买断硬件，本地推理就无需再按Token向云端付费。后摩管这叫「端边Token工厂」。

初创公司Deepshard打造的Truffle 1，直接把自己定位成7×24小时在线的「私有AI外脑」，此次与后摩合作的版本同样搭载M50芯片。
你交给它的项目资料、日常聊过的工作习惯，都会留在设备本地。之后处理同一个项目，Agent就能直接调取这些长期记忆，省去每次都要从头交代背景的麻烦。
只要你点头授权，它就能自己钻进Slack和Gmail里帮你查消息、翻邮件，等到真要动手发信或执行操作时，再交由你拍板确认。
哪怕你关掉对话框去忙别的，开发者写好的后台应用也能定时往里喂入最新的项目进展，让它时刻保持信息同步。
对于开发团队来说，平时顺手的工具直接走MCP就能接进来，现有的软件也不用推倒重写，调一下兼容OpenAI格式的接口，就能直接跑在这台设备的本地模型上。

同样是这个场景，绿联把M50塞进了家庭AI中枢HomeAgent HA100 Pro里。家里的私密照片、监控画面，AI在本地就能识别、整理，不用上云。
聊趣智能更会玩，他们的ClawHouse X1给Agent配了个可定制的全息形象。放在办公桌上，它是帮你理日程的数字员工；搬进书房，就成了陪孩子练对话的学习伙伴。

智能移动终端：彻底断网跑35B的纯血国产本
有些单位的电脑，天生就不能插网线。
在政务、金融证券这些行业，「离线可用」是硬要求。
长城N90 Pro笔记本走的是全栈国产路线，装的是银河麒麟V11系统，靠着M50在完全断网的状态下跑35B大模型，每秒30个Token，写文档、做纪要都可以离线完成。

M50能跑通麒麟系统，是因为它适配了主流的操作系统和CPU架构。后摩表示，M50是国内唯一做到这一点的高算力端边AI芯片。

具身机器人：记得住全家人习惯的AI管家
到了客厅，星灵陪伴机器人面临的是另一道题。

装上自带160TOPS算力的M50后，星灵把情绪感知和长期记忆全部留在了机身内部，数据一步都不出家门。

边缘推理：一台机器，装下一堂千亿模型实训课
高校想教学生玩大模型，又不敢把数据和课件全放到公有云上，怎么办？
星网教育上了一台实训一体机，里面插的是后摩LM5040加速卡，单卡集成4颗M50。
整台机器可提供3200TFLOPS以上的算力、1.5TB以上的内存！千亿大模型可以部署在学校本地，算力管理平台和配套课程一起交付。

从300克的掌上盒子、纯血国产笔记本，到客厅里的陪伴机器人和校园服务器，核心虽然都是同一颗M50，面对的模型、系统和场景却天差地别。
在这150多个项目里趟出来的适配方案和调优参数，被后摩一笔笔存进了这次开源的软件栈里，攒出了一座实打实的「工程经验银行」。
而现在，这座银行正式向所有开发者敞开了大门。

仓库要够大，马路得够宽
软件能这么痛快地交底，离不开后摩在芯片底层架构上的破局。
在传统芯片里，数据存在「仓库」（存储单元），计算在「车间」（计算单元），两边隔着老远，得不停地来回倒腾数据。AI计算里60%到90%的电，全耗在了这段路上。
而后摩的方案，则是基于全新的SRAM存算一体技术。换句话说就是，数据存在哪儿就在哪儿算。
跟传统方案相比，后摩可以把芯片面积砍掉约70%，功耗降到约十分之一！

但这还只解了一半的题。如今的大模型分成了两大流派，对硬件的「胃口」截然相反。
MoE（混合专家）模型每次只喊几个「专家」干活，可没干活的专家也得占着位置，所以它需要的是一个足够大的「仓库」（超大容量）。

Dense（稠密）模型正好相反，每次推理几乎所有参数都要倾巢而出，数据得像洪水一样冲进计算单元，所以它需要的是一条足够宽的「高速公路」（极高带宽）。

一种架构想同时搞定这俩？很难。
于是后摩分出了两条技术路线。
2D CIM主打「大容量、高算力」，用传统2D封装，外接GDDR、LPDDR5等内存，专门对付MoE模型和图像、视频生成。
3D CIM主打「极致带宽、高算力」，专门对付Dense模型。带宽跟上了，算力才不会干等数据。

说到3D，现在很多人在搞3D堆叠，也就是把存储芯片一层层叠在计算芯片上。
这相当于把仓库搬到了工厂隔壁，路是短了，可数据进了工厂，还是得在老流水线上来回倒腾。
而后摩的3D CIM，连工厂里的流水线都给换了。
在它的堆叠里，最底下负责计算的逻辑芯片，用的正是SRAM存算一体。
上面叠着的存储负责近距离喂数据（近存计算），下面的存算一体芯片就地消化（存内计算）。两层一起减少数据搬运，从而释放「1+1大于2」的倍增效应。

这还远没结束。
目前的3D CIM用的是DRAM，往后还能换成更便宜、更省电的Flash、RRAM。
在今年的全球AI芯片峰会上，后摩已经披露，下一代3D CIM芯片取得了阶段性成果。

硬件分了两条路，跑的却是同一套软件。开发者学会一套工具，换了芯片，稍微做点适配就能接着跑。

当年做OpenCL的人，这次把家底开源了
说起「开放」，后摩智能创始人兼CEO吴强算是老熟人了。
早年他在AMD总部做第一代GPGPU（让显卡也能做通用计算）的核心研发，也是OpenCL创始团队的核心成员。而OpenCL本身，就是一套谁都能用的开放计算标准。
后来，他又去Meta搞过芯片集群的能效优化，回国还当过地平线的CTO。
如今在自己创办的芯片公司里，他把最核心的软件栈也开源了。这次大会致辞里，他给这件事定下的调子是「带头开放，高效赋能」。

从芯出发，向端而生
对终端厂商来说，拿到源码，就等于把主动权牢牢攥在了自己手里。
调用方式不顺手？自己改。想加个独门功能？在现有工具上二次开发。
出了Bug，团队能自己查看代码、定位问题，不必只等闭源SDK（只给工具、不给源码的开发包）的厂商排期修复。
后摩也表示，会快速响应Bug反馈，新功能、新需求随时可以提。
新伙伴积累的适配经验、优化过的代码，也可以补充进这套工具链，供后来的团队复用。
这次到场的，就是这样一群伙伴。做终端的、搞系统的、写框架的、出方案的全来了，联想、中电长城、绿联、麒麟软件、聊趣智能等还上台，分享了各自的落地经验。
芯片在底层撑起本地算力，开源软件在中间铺好跑道，开放生态再把上百个项目攒下的实战经验变成公共底座。

Linus之父全新分支名字直接带「llm」

Linus之父这次指挥Claude Code动刀的地方，正是Linux最核心的「内存管理」机制。

Linux内核用page cache缓存文件数据。

在日常多并发业务场景中，一个常见操作是：多个线程同时去小块读取同一个文件。

按现有的机制，每次读取都必须在对应的内存块（folio）上修改原子引用计数。

这就导致CPU核心之间疯狂执行lock cmpxchg和lock decl，在硬件底层引发剧烈的缓存行颠簸。

早在2024年，内核核心开发者Matthew Wilcox就指出了这个来自真实客户生产环境的顽疾。

在Linus自己的测试机上，8线程并发小读时，这个瓶颈占到了所有「Load HITMs」开销的99.92%，几乎吃满了CPU的总线带宽。

而Claude接到的工作，也跨过了「补几行代码」的阶段。

它参与实现方案，编写用于检验方案的程序，还帮助梳理潜在问题。

这些环节连在一起，才像一次完整的工程尝试。写出来的代码要能运行，运行结果要能测量，测到的提升要能解释。

补丁说明也有实际用途。其他维护者需要知道，为什么要改、哪些路径受影响、作者检查过哪些情况。

AI把初稿写出来之后，这份说明仍要和代码、测试数据对得上。

公开到这个程度，后续讨论才有抓手。Linus那句「在我的指导下」，分量就在这里。

吞吐量从1000万，暴涨至 3300 万

测试中，Linus使用的是一台搭载Core i7-8565U的笔记本，4核8线程，文件系统为ext4。

测试让多个线程反复读取同一个、大小为一页的文件，每次只读16字节。

8线程吞吐量约为原来的3倍，单线程的提升约为一成。

差距为什么这么大？关键藏在「大家都读同一个文件」里。

Linux会把文件数据缓存在内存中，这就是页面缓存。后续读取可以直接从缓存取数据，省去再次访问存储设备的时间。

可缓存里的内存也会被回收。内核必须确保：线程还在读取时，这块内存没有被释放、转给其他用途。

原来的读取路径，会给承载缓存数据的内存对象增加引用计数，读完再减回去。这个对象叫folio，可以把它理解为内核管理的一组内存页。

问题是，几个线程一齐读，大家就要反复修改同一个计数。

为了保持数据一致，处理器核心之间得来回传递包含这个计数的缓存行。一次读取只有16字节，读取本身很快，维护计数的开销反倒成了瓶颈。

就像八个人都来翻一本书，每次翻页前后，都得争着修改同一张登记表。

Linus这组补丁，试着省掉读取路径上的这道手续。

它的做法是：缓存中的内存被移除后，延迟一段时间再真正归还给内存分配器，借助RCU机制，让已经开始的相关读取有机会完成。

这样，线程可以在受保护的读取区间内直接复制数据，减少对共享引用计数的争抢。

这也解释了，为什么多线程共享同一文件的测试收益尤其明显。

放到Google内部整体看，Argon在Antigravity中的使用，让Agent代码提交量增加超过35%，代码回滚减少近三分之一。
Isomorphic Labs拿它整理药物研发中的复杂PDF和专利，过去通常要几周的资料工作，如今压到几小时。

近60年核聚变猜想AI又往前推了一步
工程师让Argon啃代码，科学家把更难的问题交了出来。
这不，Argon也在核聚变猜想领域，立下大功。
核聚变领域，仿星器需要用复杂的三维磁场约束高温等离子体。磁场怎样保持平衡，是设计中的一道硬题。
1967年提出的「Grad猜想」认为，除某些特殊构型外，一类满足严格条件的平滑平衡解并不存在。
最近，马里兰大学教授Matt Landreman等研究者找到了反例。
这一次，谷歌团队与Landreman合作，借助Argon进一步去掉原有解中的「仿星器对称性」限制，找出了更广一类精确解。
团队把已有论文和问题交给Antigravity里的Gemini 4 Agent，几小时内就得到有希望的候选解。Argon还编写了验证代码，研究者随后独立重算、核对每一步推导。

有了这些精确解，研究者就多了一套「标准答案」，可以检查仿星器模拟程序算得准不准，再拿它研究更复杂的磁场。
另一组成果，已经在实验室里亮了起来。
谷歌科学家和Argon一起设计了5种新酶，用来切开分子中的特定化学键。过去常要花几个月筛选、调模型的设计环节，这次几小时就完成。
随后，科学家把候选酶做出来，5种都能催动目标反应。
检测用的分子被切开后，产物会在紫外光下发亮，设计有没有用，直接看得到。
Argon还帮谷歌给量子纠错提了速：优化内部AlphaQubit纠错解码器，让单位时间处理的数据接近翻倍。
它还写出一个计算反正弦的量子子程序，并通过Lean形式化验证。与已发表的量子CORDIC方案相比，这段程序的时空开销降到了1/100以下。
在罕见病研究中，Gamow Labs用Argon分析去标识化的新生儿基因组，发现了一例被常规软件漏检多年的染色体重排，并解释了漏检原因。

全网开测，3D世界也太能打了
到了网友手里，Argon的画风立刻变了。全球上线之后，一批Argon实测新鲜出炉。
BridgeMind让六大模型，做同一道熔岩灯题。
结果显示，Argon不到2分钟、花费0.18美元；同组Opus 5.5用了9分35秒、花费1.27美元。透明灯体里，发光的熔岩已经流动起来。

Gemini 4 Argon巧用傅里叶旋转圆，勾勒出来一只打工羊驼。

3D物理测试，成为全网清一色主流。
开发者一手对比后，大呼Gemini 4和Astra都是3D之王。

下面Gemini 4徒手搭出一个3D版的鲁布·戈德堡装置，从重力滑行到机关弹射，直接跑通了复杂的3D物理长链条因果推理。

网友YU则用两次指令、约9分钟、0.88美元，做出了Three.js版宫古岛海景。
浅滩、珊瑚、热带鱼和远处的大桥都在，还能切到水下。画面纯代码生成，没有使用外部图片。

网友Chiao让模型照着参考图，用SVG重画初音未来，并把绘制过程做成动画。
轮廓、色块、发丝和高光逐步补齐，人物就这样从代码里一点点出现。

我们也出了一道题：把下班后被工作消息追着跑，做成真正能玩的小游戏。
《别让已读回执追上我》里，小人拎包往外跑，红色通知从四面追来。按「收到」，最近的通知停住两秒；回一句「马上」，眼前消息清空，十秒后却迎来双倍追兵。
这一局，前40秒我们一直满血，绕会议桌、穿走廊，把通知甩在后面。可之前许下的「马上」集中到期，追兵越涌越多。

最终，逃亡停在52.5秒，离家门解锁只差7.5秒。

谷歌，把家底压上战场
回看这次发布，谷歌已经把积累二十多年的工程体系，推到了AI竞赛的最前线。
Chrome交出庞大的代码库，Gemma交出推理程序，DeepMind的科学家交出研究难题。Argon在真实任务里受检验，做出的改进，又回到谷歌自己的产品和研究中。
今天的AI，已经开始给明天的研发抢时间了。
AI竞赛越往前走，争夺的就越接近科技公司的根基：谁能更快写出软件，谁能更快验证想法，谁能把下一代工具提前造出来。

对谷歌而言，这是一场必须把家底压上去的仗。浏览器、开发工具、机器人、科学实验，曾经分散在庞大帝国里的力量，如今正向同一个方向汇集。
谷歌要用二十多年的积累，为自己争一个继续定义未来的位置。
这一次，从模型到工具，再到产品，谷歌的反攻全面展开。

新智元报道

在科技巨头的牌桌上，从来没有哪一次下注，像这次这般疯狂。

这次豪赌的筹码，高达 1000 亿至 2000 亿美元。

如果新模型失败，Meta将面临严重的财务危机。

万亿市值的Meta帝国，已经绑在全速冲向悬崖的AI列车上。成功了，会加冕王冠；失败了，前面是万劫不复的深渊。

AI竞赛，居然已经白热化到了这个程度？

夏威夷「恐怖团建」：CFO绝望警告，小扎下注2000亿！

这场千亿生死局背后，有什么惊天内幕？

近日，Stripe联合创始人John Collison在他的播客《Cheeky Pint》中，把扎克伯格和 Alexandr Wang 请进了一家爱尔兰风格的酒吧。在两小时的推杯换盏中，不少猛料被曝了出来。

时间拉回去年年底。

那时的夏威夷，阳光明媚。Meta 的核心高管团队齐聚于此，进行着一年一度的高管团建。

从表面上看，这是一场喝着鸡尾酒的轻松聚会。但整场聚会上，实际是暗流涌动，甚至可以说「冷汗直冒」。

刚被 Meta 斥巨资挖来的Alexandr Wang，在这里经历了终生难忘的一幕。

在团建的间隙，Meta CFO Susan Li 悄悄地把拉到了一个无人的角落。

亚历山大王透露：Susan Li 在私下里，用极其严肃、甚至带着一丝绝望的口吻，反反复复地向他发出严厉警告：「听着，如果这个前沿 AI 模型研发失败了，从财务角度来看，后果将非常、非常严重！」

CFO的恐慌，不是没有原因，因为她刚刚得知了 CEO 小扎的疯狂决定。

就在同一时期，小扎把 Alexandr Wang 叫到了跟前。当时的 Muse Wonder 乃至整个前沿模型架构，还处于极度早期的阶段，甚至连最核心的技术验证都还没做完。

但是，小扎等不及了！AI的大战已经火烧眉毛，OpenAI和谷歌的狂飙让他压力山大。

扎克伯格看着 Wang，亲自向他要最后的「底牌」：「你确定这能成吗？」

面对老板的逼问，Wang 给出了肯定的答复。

得到这句话后，扎克伯格眼都不眨，直接签发了一张支票，用于1000 亿到 2000 亿美元的基础设施投入！

这些钱，将变成GPU、数据中心、冷却塔，以及足以点亮几座城市的惊人电力。

Alexandr Wang 的爆料，彻底揭开了Meta的破釜沉舟。

这根本不是什么理性规划，这表明 ，Meta 已经将整个公司的命运，全部押在一个尚未成型的 AI 项目上。这是一场不成功便成仁的生死局。

搞砸了，公司直接面临灾难；赌赢了，股价才能起飞。

从群嘲对象到「怪物级」大模型的逆袭

背负着 CEO 的「千亿盲注」，Alexandr Wang 和团队在重压下，开启了数月的地狱级研发。

这笔钱，到底砸出了什么？

一年前，当 Meta 宣布花巨资收购 Wang 的团队时，全网都在嘲小扎是「冤大头」。

但是，Muse Wonder的跑分数据可谓扬眉吐气。

在综合智力上，完整版的 Wonder Full 拿下了惊人的 56 分！ 直接反超了Fable 5.1，仅次于 Opus 5.5。

在长时程编码能力上，Wonder 表现堪称统治级。DeepSWE 测试通过率高达约 79%。

从开源Llama，直接杀入闭源顶级 Agent赛道，Meta 在前沿长周期软件工程上，正式宣告霸主地位！

正如网友的神评论：「老天爷，必须好好研究一下小扎现在的布局，这家伙在他人生最大的一场胜利前夕，居然在悠闲地吃着烧烤！一年半前 Meta 还是最大的笑话，现在他们有了一个击败 Fable 和 Astra 的怪物模型！」

「我们做的是真实世界的 AI，不是X上的炫技玩具」

然而，Muse Wonder 刚一发布，就遭遇了猛烈的口水战。

很多人表示，它实测的表现实在拉跨，用一个词来形容，就是「benchmaxxed」。

在熔岩灯（Lava lamp）测试中，没有灯，没有玻璃，没有熔岩，甚至做了一个红色圆柱体。

这效果实在让人大跌眼镜！

对此，Alexandr Wang 亲自下场硬刚。

他在X上毫不留情地反击：

在开发 Muse Wonder 时，我们的目标是构建一个对真实世界、真实人类执行真实任务有用的模型。我们关注的是那些在推特上看起来不那么『光鲜亮丽』的东西（比如不去做那些花哨的3D游戏演示）。

这就是委婉承认技不如人！

大V Token Gremlin 表示：「Muse 在写 Three.js时简直糟透了！连写个简单的Minecraft克隆版都惨不忍睹。真让人失望。」

更尖锐的质疑来自定价策略。

有开发者指出，目前开放 API 调用的「残血版」 Muse Wonder，跑分只有 52 分，但单价却和跑分 58 的 Opus 5.5 一模一样（每百万 token 输入 $4/输出 $20）。

真正的完全体 Wonder Full 却只开放给订阅用户。

真正的杀手锏：Active Memory 与 Active Focus

在《Cheeky Pint》播客中，扎克伯格和 Wang 详细拆解了 Muse Wonder 之所以被称为「怪物」的真正原因——Active Memory 和 Active Focus。

正如有的开发者所说：「真正值得关注的不是片面的跑分，当模型真正介入你的电子邮件、日程安排和个人文档时，它的 Active Memory 会有多可怕——这才是前沿模型拉开差距的地方。」

Active Memory：它有着跨时间的超级记忆。Meta 官方表示：「我们投入了巨大的精力，确保模型能记住几天、几周甚至几个月对你重要的事。」它不再是一个「金鱼记忆」的聊天机器人，而是一个深深记住你所有偏好、习惯的赛博分身。

Active Focus： 以往的 AI 遇到报错就会摆烂。但 Muse Wonder 被输入了海量的「真实世界失败场景」。当它执行任务卡住时，它会主动寻找替代方案；在进行关键操作前，会停下来找你确认。

在演示中，Muse Wonder 能够持续不断地在网上搜寻租房信息，根据个性化条件进行过滤，甚至自主联系房东！

这是一个真正 24 小时为你打工的「超级个人助理」。

扎克伯格的反共识：AI 不会赢家通吃！

既然砸了这么疯狂的筹码，Meta 到底图什么？

在播客中，扎克伯格给出了他的判断：「AI 绝对不会是赢家通吃。」

他不相信世界会被一个像 OpenAI 那样的「上帝大模型」垄断。相反，他坚信未来将属于无数个人超级智能。

这也解释了为什么 Meta 组建了 「超级智能实验室」，为什么他们提出了「智能体商业」和「超越智能手机」的硬件愿景。

想象一下，未来你戴着 Meta 的智能眼镜，里面住着拥有 Active Memory 的 Muse Wonder。

你的个人 Agent 会去和商家的 Agent 沟通、砍价、购买商品。

如果真的实现，Meta将彻底重塑全球的数字商业模式。这就是那 2000 亿美元想要买下的未来！

现在在硅谷，你要么烧掉几千亿赌一个明天，要么抱着几百亿的现金等死。

扎克伯格选择了前者。他把 Meta 推上了赌桌，把枪上了膛，然后用 Muse Wonder 扣下了扳机。

目前来看，这颗子弹正中靶心。

Meta 没有走向财务灾难，反而成功杀入了前沿模型的顶级赛道，把个人超级智能带到了数十亿用户的手边。

至于Muse Wonder究竟好不好用？让我们且待模型开放。
