2. 刚刚，Claude彻底解禁第三方应用！

10-15 07:51 原文链接

新智元报道

Claude王者归来了。

就在刚刚，Anthropic祭出王炸，Claude即将大爆发！

简而言之：Anthropic彻底扫清了政策障碍，正式确认Claude订阅用户的额度，可以无缝接入第三方App和Agent！

这是大模型下半场竞争中，Anthropic的关键一步。

从此，开发者与用户之间的「双重收费」魔咒，正式被打破。

Agent生态大航海时代，将全面开启！

悬在开发者头顶的达摩克利斯之剑，断了

Claude的平台政策经常朝令夕改，这让广大开发者困扰不已。

过去几个月，社区里流传着一种担忧的解读：Anthropic可能会限制甚至封杀第三方应用对Claude API和Agent SDK的调用。

理由很简单——肥水不流外人田。

AI大厂自己也要做生态，为什么要让第三方开发者用自己的底层模型赚钱？

这种担忧，就是悬在开发者头顶的达摩克利斯之剑。谁也不敢拿身家性命赌。

但现在，Anthropic直接断绝了这种担忧。

10月7日，Anthropic偷偷更新了官方支持页面——从此，第三方应用全面放行！

链接：https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

文件明确指出，Claude Max和Team计划的用户，其月度API Credits可直接用于：

Claude Agent SDK

Claude -p 命令

Claude API

Claude Managed Agents

所有使用上述技术的第三方App

这个消息一出，网友们立刻喜大普奔，互相传递着好消息——

从此，允许使用Claude Agent SDK的第三方应用，来消耗订阅额度了！

为了彻底打消疑虑，多位Anthropic官方员工甚至亲自现身Hacker News（HN）评论区，盖楼证实了这一政策。

「没有任何反对意见。」

「支持继续使用该技术。」

「不用额外付费。」

字字句句，斩钉截铁。

政策明确了。红线消失了。警报解除了。

为什么这是一次历史性的松绑？

要理解这场狂欢的深度，必须看懂过去AI应用生态。

在大模型时代，应用的商业模式一直是个巨大的痛点，可称之为「双重收费悖论」。

作为用户，你每个月花几百块钱订阅了ChatGPT Plus或者Claude Pro。作为开发者，你做了一款非常棒的编程助手App，底层接入了Claude的API。

当用户使用你的App时，API会产生费用。这笔钱，Anthropic要向你（开发者）收。

那么，你（开发者）该怎么活下去？

你只能向用户收费。

于是，荒谬的一幕出现了：用户明明已经买了Claude的会员，但在使用第三方Claude应用时，还要再付一次钱给开发者。

这是就是双倍付费。

这直接导致了两个致命后果：

第一，用户不愿意买单。

我都有Claude会员了，凭什么还要给你交钱？

第二，开发者放不开手脚。

API调用成本太高，稍微跑几个复杂的Agent任务，我就破产了。

这就形成了一个死局。大把优秀的创意胎死腹中。沉没成本太高，容错率太低。

Anthropic的新政，这次彻底放行，本质上确立了「BYOS」（Bring Your Own Subscription——自带订阅）模式。

你开发了一个第三方App？没问题。

用户想用？也没问题。

只要用户是Claude Max或Team计划的会员，他们在你的App里消耗的算力，直接从他们自己的月度API额度里扣！

这意味着什么？

对用户而言：一卡通行，全网白嫖。

买了一个Claude的高级订阅，不仅能在官网聊天，还能无缝对接各种牛逼的第三方自动化工具、代码补全插件、数据分析Agent。无需二次付费，没有额外门槛。

你的订阅，真正变成了「AI时代的通行证」。

对开发者而言：成本归零，专注创新。

再也不用盯着API账单心惊肉跳了！你可以大胆地设计最复杂的Agent架构，调用最消耗算力的思维链（Chain of Thought）。

只要用户自带额度，你的计算成本就是零。你可以把100%的精力，全部砸在产品体验和功能创新上。

Claude的程序员们，现在可以在第三方环境中使用你的Claude订阅了，不需要支付额外费用！

这不仅省钱，或将彻底解放对生产力。

Anthropic的阳谋：用「开放」绞杀对手，赢下下半场

Anthropic做出这个决定，绝不是浪子回头。

这是商业阳谋。

大模型的竞争，已经进入了下半场。

上半场，大家拼的是参数量，是跑分，是「聊天」的智商。

下半场，大家拼的是行动力，是Agent（智能体）生态。

谁能让AI接入真实的业务流，谁能让AI自动写代码、发邮件、操作软件，谁就能赢下未来。

在这个节骨眼上，路线分化了。

有的巨头选择了「封闭帝国」模式。

他们试图把所有的流量、所有的应用、所有的Agent都圈在自己的App里。想用我的模型？来我的应用商店。他们既做裁判，又做运动员，试图榨干产业链上的每一滴利润。

但Anthropic选择了另一种模式。

Anthropic非常清楚：一家公司的力量是有限的。你不可能自己做出全世界所有垂直领域的最好用的App。

与其把开发者当成潜在的竞争对手防备，不如把他们变成自己的「打工人」。

允许订阅额度直接「白嫖」第三方Agent，就是Anthropic加速繁荣自身应用生态的撒手锏。

试想一下接下来的画面：

因为没有了API成本的后顾之忧，基于Claude Agent SDK开发的应用会引来大爆发。

今天出来一个自动剪视频的Agent。

明天出来一个接管你整个代码库重构的Agent。

后天出来一个自动帮你处理海量Excel表格的Agent。

这些第三方应用，做得越好，用的人越多。

而用户想用这些神级App，就必须去买Claude Max和Team的订阅！

Anthropic是在用整个第三方开发者社区的智慧，来帮自己卖会员！

他们通过降低第三方应用的使用门槛和开发者沉没成本，巧妙地将全球开发者的利益与自己深度绑定。

开发者得到了免费的算力渠道和海量的高价值用户。用户得到了市面上最繁荣、最硬核的工具生态。Anthropic得到了源源不断的订阅费和不可撼动的生态护城河。

这是一场阳谋。竞争对手眼睁睁看着Anthropic的生态像滚雪球一样壮大，却很难复制这一策略——因为这需要极高的底气，以及对自家模型（尤其是代码和Agent能力）极度的自信。

行动时刻：开发者，你在等什么？

1. Claude Code桌面版暴改，一人指挥AI军团飙代码！

10-15 07:51 原文链接

新智元报道

Claude Code一夜进化！

就在今天，Anthropic正式放出了Claude Code桌面版史诗级更新！

它可以同时拉起多个对话，多线程跑任务，谁先干完了，就把结果甩回主会话。

而且，新界面把会话管理彻底重做了。

不仅支持环境复用、后续任务一键拉起，而且随手敲个/btw还能切到新标签页单独开跑。

几乎一时间，全球开发者社区被同一消息刷屏了。

Anthropic工程师Thariq更是难掩兴奋，激动地表示，「这几乎是一个v2版本」！


Claude自动分身多会话同时开工

先看这次最抓人的功能：自动创建嵌套会话。

在以前，如果想让AI同时干三件事，得自己手动开三个窗口，最后还得自己去一一核对结果。

更糟的是，任务一多，主线程就会变成灾难现场：前端代码和后端报错混在一起，想回溯某一步的修改，得在屏幕前疯狂滚鼠标。

现在，这套逻辑彻底变了。

在新版Claude Code桌面版里，只需在主对话框里把所有任务一次性交代出去。

当Claude识别到这些任务可以并行处理时，它会瞬间施展「影分身之术」——自动为每一个子任务创建一个独立的嵌套会话（Nested Session）！

更妙的是，它的信息流转机制：

  • 底层并发执行： 几个子会话在后台同时开工，各自读取上下文、修改代码、跑测试，互不干扰。

  • 主线程极度清爽： 它们那些繁琐的中间试错、几百行的终端输出，完全不会污染主对话界面。

  • 自动汇总汇报： 当每个子会话干完活后，它会自动像下属向总监汇报一样，将最终的执行结果整洁地汇总回主会话中。

这样一来，主线程自始至终保持着极高的可读性。

人类不需要去关心中间那几百行报错排查的过程，只需要坐在主会话里，像批阅奏折一样查看每个AI交上来的最终答卷。

如果某个Claude分身卡住了或者你想看细节，随时点进去就能穿透到底层。

这轮升级，让AI更容易分头干活。但工程上的验收，仍然得有人把关。

一堆AI对话，人怎么盯得过来？

几个Claude一起开工，下一秒就会碰到另一个问题：到底该看谁？

一个还在分析代码，一个正在跑命令，另一个可能已经停下来等你作决定。如果只能逐个点进去翻记录，省下来的等待时间，又会被切换窗口吃掉。

新版把这些状态搬到了更显眼的位置。

侧边栏可以让用户看清哪些会话正在工作，哪些需要自己介入。

进入会话后，实时待办清单会跟着Claude的计划推进；当它需要用户回应时，一张回顾卡片会概括这一轮的情况。

侧边信息栏则展示任务运行的位置、上下文和代码改动。


秒级切入「作战现场」一键环境复用

除了任务执行时的并发，Anthropic这次把「开工前的准备工作」也卷到了极致。

很多全栈架构师日常的开发环境非常复杂，前端在一个文件夹，后端微服务在另一个文件夹，甚至有些长周期任务需要丢在云端跑。

每次重启软件或者切换项目，光把这些目录和连接配置好，就要折腾半天。

新版Claude Code对「新建会话界面」，进行了大刀阔斧的重构。

核心目标就四个字：无缝接续。

  • 常用目录一键直达

打开界面，「最近使用过的文件夹」直接摆在最显眼的位置，无需在系统目录树里翻找，一键点击即可原地开干。

  • 自定义「环境」打包保存

现在，可以把一整套复杂的开发配置，直接打包保存为一个命名好的「环境」。

比如，好几个本地文件夹的组合、特定的SSH远程主机、或者是云端运行环境。在下次需要使用时，一键就能把整套多目录、跨端的工作台瞬间拉起。

  • 原生级Git Worktree隔离

既然是多会话并行，如果两个AI同时改一个本地文件夹里的代码，岂不是要打架？

这一点，Anthropic早就替你想好了！

在启动多会话时，新版CC直接提供了「每个文件夹独立Worktree」的选项。

只需勾选一下，Claude就会自动利用Git Worktree为不同的并行会话拉起独立的工作树分支。

A会话在重构底层架构，B会话在修线上紧急Bug，两者在物理文件层面彻底隔离，再也不用担心代码互相覆盖或本地环境崩溃。


细节控封神/btw随时插嘴，主动推荐后续任务

为何Thariq会感叹新版Claude Code桌面端「对自身能力有了极强的自我认知」？

答案，就藏在两个极具巧思的交互细节里：主动推荐与/btw支线对话。

以往的AI工具是「算盘珠子」，拨一下动一下。

新版CC在干活的同时，会基于当前改动「主动推荐」下一步后续工作。

无需打字确认，只需点击一下，后续建议就会直接作为独立会话在后台跑起来！ 此外，空输入框还会智能浮现灰色提示词建议，按Tab键即可瞬间采纳。

另一个让程序员拍案叫绝的设计，是新增的/btw指令（顺便问一句）。

在主线任务推进过程中，你难免冒出临时疑问，「顺便问一下，这个鉴权Token默认过期时间是多久」？

如今，在CC中，只需输入/btw（或按快捷键Cmd + ; / Ctrl + ;）：

  • 系统立刻在独立标签页打开支线对话，完整继承主会话到目前为止的所有上下文，无需重新解释背景。

  • 主会话继续狂奔，完全不受干扰！ 支线提问绝不会污染主线程记录。等你解开疑惑关掉标签页，主线工作依然干干净净。

这个功能看似简单，但它解决的是一个非常根本的痛点：「心流」不该被打断。

程序员最怕的就是「上下文切换税」，每次被打断后重新回到深度工作状态，可能需要十几分钟。

/btw让人可以在不打断主流程的情况下解决临时疑问，很多时候，效率就是这么一点点省出来的。

不仅如此，Claude Code还新增了「空闲压缩」（Idle Compaction）功能。

当一个会话长时间处于空闲状态时，CC会在提示词缓存即将过期（约1小时）前，自动压缩会话上下文。

这样既能保留关键上下文，又能减少Token消耗，节省使用额度。

AI编程下半场，拼的是「带队能力」

Claude Code桌面端这波大改，说白了，就是把AI编程直接推进了下半场。

它正从单一的「AI编程助手」，彻底进化为「多Agent协作工作台」。

过去两年AI Coding竞赛，大家拼的是单点能力——代码补全、单次生成准确率、SWE-bench上的跑分。

但到了今天，瓶颈已经变成了「如何让AI同时推进十个模块的开发，还能不把工程搞砸」。

正如Thariq所言，Claude Code高度清楚自己的能力，知道怎么通过孵化子会话来和人类打配合。

最重要的是，在这套新范式下，人类开发者的角色发生了根本性的位移。

单线程打工的时代正在落幕，属于每个人的「多Agent并行工程军团」，今天正式上线。
