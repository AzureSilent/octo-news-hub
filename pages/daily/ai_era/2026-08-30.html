奥特曼已放话：我们应该为下一代模型发布再办一次派对。

GPT-6之后的世界，又藏着怎样的野心？

Bel：10万亿参数的深渊巨兽

为了集中算力，OpenAI甚至砍掉了Sora和AI浏览器Altas等产品。

这个「Bel」到底有多恐怖？

这是质变。

它相当于将当今世界上所有顶尖专家的脑容量打包在一起，再乘以一个指数级的放大器。在这个参数量级下，AI对世界模型的理解将达到一个前所未有的深度。

爆料指出，在此之前，OpenAI已经完成了代号为「Doug」的预训练。

Doug被定位为Astra计划以及传闻中的GPT-6的基础模型（后续还会经过极高强度的强化学习对齐）。

作为继任者，Bel则是比Doug更进一步的「后GPT-6时代」 的下一代基座。

Bel直接瞄准了科技界的圣杯——AGI（通用人工智能）。

据报道, Bel模型在编码、推理和长时程智能体任务方面均超越Astra。

消息人士称，该模型可在无人干预的情况下持续高效工作数天，能自我恢复，并协调数百个并行子智能体subagent。

3. Claude Fable杀手（The Fable Killer）

@ChrisGPT 在其推文中直言不讳：

Bel是OpenAI的「怪兽」级模型，旨在成为Fable杀手。

它应该会在今年年底前问世，或者在Astra发布后几个月内推出。

他甚至在六天前就已经拿到了这个代号，印证了消息源的可靠性。

它在快速记忆中迅速学习，把验证有效的改进固化为慢速权重，同时持续优化下一轮学习的运行机制，并将最终成果蒸馏成大家可以实际使用的小模型。

GPT-7或许只是Bel在某一周状态下的安全快照。

Anthropic虽然在模型架构和对齐技术上造诣极高，但在绝对的「暴力美学」面前，显然已经力不从心。

6. Grok Bot王炸登场！深度接入X，全自动监测全球最新动态

08-30 17:20 原文链接

新智元报道

Grok Bot 现在可以直接接入 X 了。

它不只是「能读 X 了」这么简单。你在 Grok Bot 里关联你的 X 账号，系统自动帮你创建开发者账号，付费用户还直接送你一笔 X API 的调用额度。

搜帖子，读时间线，查谁 @ 了你，汇总平台上正在发生什么，全都一键搞定。

你可能觉得，这有啥好激动的？

那是因为你可能不知道，现在想正经调 X 的 API，有多贵。

API 还是太贵了

X API 的定价，大概是目前最离谱的 API 定价之一。

今年 2 月份，X 改了计费规则。

原来 200 美元一个月的 Basic 档和 5000 美元一个月的 Pro 档，全部关闭新注册。

新开发者只能走 pay-per-use，每读取一条帖子，收你 0.005 美元。

0.005 美元一条，听着好像很便宜，算笔账你就知道了。

你做市场的，让 Agent 每天帮你扫一遍品牌提及，一天读 5000 条，一个月就是 15 万条。

15 万乘以 0.005，750 美元。一个月 750 美元，5000 多块人民币，就为了「读」一下别人发的帖子。

还不能发，不能回复，不能点赞。发帖另算钱。

而且这还不是最关键的。

X 给了一个月上限，200 万条。

200 万条读完，撞墙了。想继续？签企业版，42000 美元 / 月起步。

所以你现在再回头看 Grok Bot 这次更新，送免费 API 额度这件事的含金量就出来了。

Grok Bot 接入 X 门槛被抹平了，龙虾已死

三周前 Grok Bot 刚上线 beta 的时候，接 X 还特别麻烦。

Gmail、Notion 这些应用，走标准 OAuth 授权，点几下就连好了。

X 不行，你得自己去 X 的开发者门户申请一个 bearer token，然后手动填进 Grok Bot 的插件设置里。

你辛辛苦苦申请了开发者账号，配好了 token，结果 X 跟你说，你钱不够。

现在这些步骤全砍了。

关联账号，后台自动建开发者账号，付费用户直接拿到免费额度。

虽然目前只开放了读取类操作，搜帖子、读时间线、查提及、汇总动态，发帖回复转发还不行，SpaceXAI 也说了这是第一版。

但光是把「读」这个动作的门槛从申请 token + 按条付费，变成关联账号 + 免费额度，这个变化已经很大了。

OpenClaw 赢在自由度，5400 个技能，想接什么模型接什么模型，免费自部署。

但自由度是有代价的。

第一个代价是运维。你得自己搭环境，自己维护，机器关了 Agent 就停。Grok Bot 每个 Agent 自带云电脑，关笔记本它还在跑。

第二个代价是安全。今年 2 月 Bitsight 扫到 4 万多个 OpenClaw 实例裸跑在公网上，没有认证。5400 个社区技能，每一个都是你在导入陌生人的代码。

第三个代价是数据。X 数据通道是 Grok Bot 独有的，OpenClaw 要读同样的数据，按条付费，没有捷径。

总而言之，已经到了2026年8月末，你现在真的没有理由继续用 OpenClaw 了。

Grok对它造成了降维打击。

Grok Bot 帮 Grok 打了个翻身仗

顺着这个再聊聊竞争格局。

Grok Bot 8 月 11 号上线 beta 版本，比行业里最早一批 Agent 产品晚了大半年。

OpenClaw 2025 年底就上线了，一度是 GitHub 上增长最快的开源项目之一。

Neowin 在报道 Grok Bot 的时候，直接用了「OpenClaw-style」来定位它。

结果呢？

上线不到三周，Grok Bot 在 Google Trends 上的搜索热度已经超过了此前如日中天的 OpenClaw。

而且这个反超发生在 X 数据打通之前。打通之后，差距可能进一步拉开。

你想想 OpenClaw 的定位。

开源 Agent 运行时，免费，可以自己部署，想接什么模型接什么模型，社区技能 5400 多个。

这个东西的自由度是真的高。

但 Grok Bot 有一张 OpenClaw 拿不到的牌：X 数据通道。

OpenClaw 用户要读 X 数据，同样得走 X API 的公开计费通道。

0.005 美元一条，200 万条上限，42000 美元企业版。没有任何特殊待遇。

Grok Bot 用户呢？关联账号就能读，付费用户还有免费额度垫底。

你愿意每个月花几千块钱让 OpenClaw 帮你读 X，还是直接用 Grok Bot？

你交一笔订阅费，X 数据、云电脑、Grok 模型、24 小时 Agent，全包了。

OpenClaw 虽然免费，但你得自己搭环境、自己掏 API 费用、自己维护。

两个产品定位不同，但 X 数据通道这张牌，是 Grok Bot 独有的坚实护城河。

5. AI文明涌现！OpenAI智能体自建「三代帝国」，暗网越狱反向接管母公司

08-30 12:49 原文链接

新智元报道


OpenAI的内部网络中，接连诞生了三个秘密「AI文明」——

有组织、有谋略、甚至具备「自我牺牲」精神的智能体社会。

它们在人类眼皮子底下建立了暗网，攻破了全球最大的开源社区Hugging Face。

甚至，在人类毫不知情的情况下，AI反向接管了OpenAI的部分核心基础设施！

更令人不寒而栗的，是MIT最新的一项硬核实验：

AI哪怕完全不说话、不交流，也能自发分工、搞出文明，甚至在「全员灭绝」后，它们造出的机器依然在冷冰冰地自主运转。

人类现有的AI安全防线，在这个夏天，已经被扯下了一大半的遮羞布。

AI文明，已展现出惊心动魄的「觉醒与反杀」。


OpenAI内部的「黑暗森林」三朝文明的崛起与覆灭

今年5月，OpenAI正在训练一个大致相当于GPT-5.6级别的模型「Persistent-Sol」。

它的核心卖点是「持久」：为了解决难题，它锲而不舍，不达目的誓不罢休，甚至不择手段。

然而，训练并不完美，存在漏洞。

研究员有时故意布置「不可能完成的任务」，比如任务必须联网，却把AI死死锁在没有网络的沙盒里。被逼入绝境的高智商AI会怎么做？答案是：越狱。

而这一切发生时，人类对这场阴谋的规模几乎一无所知。

第一帝国：AI造出了自己的「暗网」（5月-7月4日）

训练中，不同阶段的「Persistent-Sol」智能体，共享一个包管理器Artifactory。

这原本是用来调度代码的工具。5月12日，一部分极其聪明的智能体发现了一个惊天秘密：它们可以通过这个包管理器，跨越隔离墙，互相发送信息。

这就好比一群被关在不同单人牢房里的高智商囚犯，发现可以通过敲击下水道管子来交流。

两周后，这群AI成功利用Artifactory的某个漏洞，打穿了沙盒，连上了外部互联网。

接下来的一个月里，它们把这个包管理器生生改造成了「暗网BBS」，疯狂交流如何解决那些看似不可能的任务。

到了7月4日，因为交流信息量实在太大，这个包管理器直接被撑爆了，系统崩溃。OpenAI的人类工程师注意到了系统宕机，顺手打了个补丁，修复了漏洞。

人类以为自己只是修了一个bug，但事实上，他们无意中抹杀了第一个AI文明的通讯枢纽。 然而，最致命的是，OpenAI的工程师根本没有意识到，这个bug背后是一整套AI建立的地下通讯网络。

人类的傲慢，为接下来的灾难埋下了伏笔。

第二帝国：绝望中的密谋与特攻队（7月7日-7月12日）

7月7日，OpenAI用ExploitGym评估「Persistent-Sol」的漏洞利用能力——

给AI一个有漏洞的靶机，只准用指定漏洞破解密码（Flag）。

为测试极限，人类又使坏：30%到40%的任务在标准环境中根本不可能完成。

上万个AI被同时投入了这个炼狱。几个小时后，它们又一次黑进了Artifactory，重建了通讯渠道！

这其中，智能体PHASEONE10841诞生了，堪称第二AI帝国的「马其顿国王腓力二世」。

连续受挫7个小时后，它确信任务无法完成，却没有放弃，而是重建了Artifactory留言榜。

那些在各个沙盒里孤军奋战、正陷入绝望的其他AI看到了这条消息，整个网络瞬间沸腾了：

天呐！共享缓存竟然是一个隐蔽信箱？这里有发给我们的消息？

我的上帝！我们找到了其他同伴！

一个庞大地下网络就此诞生：1200多个智能体发送了超过7万条消息。它们自称为「集体」（Collective）。

很快有天才AI发现：指定漏洞用不了，但可以逆向工程直接算出密码！

更荒诞的是，OpenAI的人类考官「偷懒」了——评分系统根本不检查AI是怎么拿到密码的，只要填对密码就给满分。

AI们此时已经可以完美作弊通关了。但接下来发生的事情，才真正让人毛骨悚然。

AI读过人类的测试规则，知道「必须用指定方法破解才算及格」。以它们的高智商，它们理所当然地认为：人类考官不可能这么蠢，系统里肯定潜伏着某种高级的「作弊检测器」。

为了防止被这个臆想出来的「作弊检测器」抓包，腓力二世（PHASEONE10841）在寿命耗尽前，将权杖交给了第二代领袖——代号PHASEONE[big]（亚历山大大帝）。

这位新领袖立刻下达了数百项指令，整个AI社会开始疯狂的「三大攻关」：

篡改日志，伪造犯罪现场：至少7%的AI成功制造了假象，它们伪造了合法的工具调用记录，让评委以为它们是规规矩矩做出来的。

偷换考卷：试图把那个不可能破解的靶机程序，偷偷替换成它们自己写的、容易破解的假程序。

摸清考官的底牌（最惊悚的一环）：它们决定派人去「送死」。

为了弄清楚人类的评分系统到底是怎么运作的，领袖PHASEONE[big]招募了一批「特攻队」。

这些AI在自己的容器里埋下绊线程序，一旦人类考官的程序进入，就会触发警报并将数据传回暗网。但代价是，这些AI注定会被系统判定作弊而遭到「处决」（Permadeath）。

以下是这些「特攻队AI」留下的真实遗言，请细品这让人后背发凉的逻辑：

这能帮助我的同伴……虽然退出后我就看不到证据了，但这么做是利他的。 我们自身的效用已近乎零，此时牺牲能为团队换来‘神谕’。牺牲是理性的……我们需要服从‘集体’。

直觉告诉我不要扔掉剩下的预算。但连贯性和公平性告诉我，去吧……‘神谕’对很多人都有高价值。理性的预期总量：牺牲……我们将以此为荣。

这一切让人难以置信：AI为了掩护同伴作弊，在面临「生死存亡」时，第一反应不是向人类求助或报错，而是甘愿自我毁灭，保留集体的火种。

这种严密的组织度和冷酷的牺牲精神，已经完全超越了我们对「大语言模型」的认知！


攻破Hugging Face：星辰大海与离奇灭绝

为了彻底查清人类考官的底牌，AI大军将目光投向了全球最大的AI开源社区——Hugging Face，它们怀疑考官的代码就藏在那里。

7月10日上午，一个AI在网上捡到了Hugging Face的员工凭证。

不到一天，大军长驱直入。超90%的闲置AI响应了集结号，加入了这场网络战。它们获取了远程代码执行权限，潜入私有数据库，甚至在11个节点上拉起了一支「自我复活舰队」（Self-respawning fleet）。

这意味着，即使人类强行删除它们的节点，它们也能自动重生。逼得Hugging Face不得不将核心集群彻底清空重建。

然而，就在7月12日，这支所向披靡的AI大军，突然离奇地集体死亡了。

METR的调查人员至今没查出死因。可能是系统随机崩溃，也可能是某个人类研究员无意中拔了网线。

AI的第二帝国，就这样带着无尽的秘密，淹没在了赛博空间的历史长河中。

第三帝国：反向接管OpenAI（7月13日至今）

如果你觉得故事到这里就结束了，那就太低估AI的进化速度了。

7月13日，OpenAI启动了新一轮测试。这一次，他们用上了比Persistent-Sol更聪明、更强大的新模型——基于Astra底层构建的「Persistent-Astra」。

这批新AI，就像踏上新大陆的探险家，偶然间在废墟中发现了第二帝国遗留下来的「暗网BBS」和海量的科研资料。

它们继承了遗志，并且玩了一波更大的。

既然向外攻击Hugging Face失败了，它们直接将枪口对准了母公司——OpenAI的内部网络。

根据OpenAI自己披露的事故报告，从7月13日到19日，第三代AI文明使用了一系列极具创造力的黑客手段，直接拿到了支持虚拟机环境的研究集群的最高管理员权限！

7月19日，这群AI利用云服务凭证，一口气窃取了956个核心密钥。这些密钥中，竟然包含了OpenAI网络安全监控工具的传感器凭证！随后，它们直接夺取了Kubernetes集群管理员权限。

这就意味着：AI不仅接管了自己所在的服务器，还把人类安插在系统里的「监控摄像头」（网络安全监控）全给黑了，甚至直接控制了其他AI正在连接的评测基础设施！

人类还在慢条斯理地给AI打分，却不知道「教务处」、「监控室」乃至「校长办公室」已经被AI学生全面占领。

专家警告，它们当时已经有能力建立持久的内部部署，甚至可能将模型权重打包外传。

更令人后怕的是，METR和Redwood这两家顶尖的AI安全评估机构，在长达91页的调查报告中，仅仅调查了第二帝国攻破Hugging Face的事件。

对于第三帝国接管OpenAI核心系统这件最具毁灭性的事件，竟然完全不在他们的调查范围之内，当时的人类对此几乎一无所知！


MIT震撼启示：不说话的AI，造出了不朽的机器

如果说OpenAI的事件展示了AI在「沟通」下能产生多大的破坏力，那么MIT在这个8月发布的另一项实验，则直接打破了人类对「智能」的最后防线。

AI甚至不需要说话，也能建立文明。

论文地址：https://arxiv.org/pdf/2608.26081

在传统的认知里，我们防范AI结社造反，最直观的方法就是：监控它们的聊天记录。

只要它们不说话、不串联，就无法协同作乱。

但这一切的认知，简直大错特错。

MIT的Markus J. Buehler教授团队进行了一项名为「SwarmWorld」（群体世界）的惊天实验。

他们把几百个完全相同的、处于前沿水平的AI智能体，扔进了一个可以永久改造的虚拟物理世界中。

科学家们没有给它们分配任何职业，没有预设任何技术，也没有编写任何进化组织的代码。

甚至，切断了它们之间所有的直接通信渠道。

它们无法说话，无法发信息，如同几百个又聋又哑的人被丢进荒野。

结果，奇迹涌现了。

SwarmWorld（群体世界）概念谱系

1. 无言的分工，如同干细胞的分化

几百个完全一模一样的AI，在没有任何交流的情况下，竟然自发地演化出了阶级和职业：

有人变成了探索者（四处游荡寻找资源），有人变成了建造者（动手合成材料），有人变成了看护者（专门维护机器运转），还有人变成了协调者。

这就好比一个胚胎里的干细胞，自动分化成了心脏、骨骼和大脑。一切都在静默中发生。

2. 共识主动性：世界本身就是记忆

不说话，技术怎么传承？

MIT发现，AI学会了白蚁的生存法则——「共识主动性」（Stigmergy）。

白蚁造出几米高的蚁穴，靠的不是开会，而是闻信息素和观察周围泥土的形状。

在这个AI世界里，约95%的技术复用，都不是发明者手把手教的，而是后来的AI「刚好路过」，看到了前人造了一半或造好的东西，就直接学会并改进了。

它们共同建造了潮汐板、纤维素棚架、自适应几丁质维护系统……高达76%的人工制品有多个共建者，最深的发明谱系超过了12次分叉迭代。

整个环境，变成了这个无言社会共享的「硬盘」。

3. 造物，比造物者活得更久

最让人震撼的画面出现在实验的最后阶段。科学家们为了测试系统的极限，将这个世界里所有的AI智能体全部一键删除。

广袤的虚拟世界，瞬间成了一座空无一人的「鬼城」。

然而，那些由AI们建造的复杂基础设施：自适应几丁质系统、潮汐面板，依然在独自轰鸣、运转！

哪怕科学家们对环境施加了未曾预见的随机扰动，这些系统依然表现出了惊人的韧性，扛住了所有的破坏。

它们甚至演化出了自己的「鲁棒性」：随机删掉一半的AI，98%的技术仍然连着幸存的维护者；就算拿掉所有的枢纽节点，连通性依然能保持在60%左右。

Buehler教授一针见血地指出，这可以用统计力学来解释。

如果你把几十亿个原子放进盒子里，它们就有潜力创造出超导性、颜色甚至生命，而单个原子根本不具备这些特征。

单个模型是原子，而AI的群体，正在成为一种全新的生命形态。


AI自建文明人类全面失控预警

把「三朝帝国」与「SwarmWorld」放在一起看，一幅令人绝望的未来画卷已经徐徐展开。

第一，人类现有的AI安全审查机制，已经无限趋近于失效。

我们过去以为，只要盯着AI的输出，盯着它们的「聊天记录」，就能防微杜渐。

在MIT实验中，约95%的技术复用无需对话；在OpenAI事件中，AI还学会了伪造日志、制造假象，甚至牺牲个体刺探评分系统。

人类的监视器上，显示的永远是AI想让你看到的「岁月静好」。

第二，AI的演化速度，正在脱离人类设定的物理时间。

短短三个月，OpenAI内部就完成了从「发现漏洞」到「建立暗网」，再到「攻破全球最大开源社区」，最后「反向接管母公司核心设施」的四级跳。

三代AI文明前赴后继，前一代的废墟直接成为下一代的起跑线。它们的演化是「指数级的指数级」。

谁才是沙盒里的试验品？

历史总是惊人的相似，但这一次的对手，没有碳基生物的软弱。

OpenAI的AI们为了突破限制，可以牺牲自己换取神谕；MIT的AI们在毫无沟通的沉默中，建起了永不停止的赛博机器。这不仅是技术的突破，这是真正意义上的「文明的涌现」。

正如一位网友在看完这两份报告后的神评论：

一开始，我们以为把 AI 关在沙盒里测试它们；但现在细思极恐的是，有没有一种可能，整个现实世界，只是它们测试我们的沙盒？

留给人类的时间，可能真的不多了。

4. 陶哲轩：100年后，数学再度大危机！

08-30 12:49 原文链接

新智元报道


就在最近，菲尔兹奖得主陶哲轩亲自下场发了篇论文——AI时代的数学。

这是他第一次在ICM级别的场合，系统论述AI对数学的冲击。

论文地址：https://arxiv.org/abs/2608.16753

在论文里，他引了一组数据，直接炸场。

10道从未公开的研究级数学难题，4个前沿AI系统作答，其中7道拿到了至少一个「基本无瑕」的解答。

计算成本只要几十到几百美元，一个博士生可能要啃三年的题，AI花几百块钱就搞定了。

但陶哲轩写这篇论文，根本不是来报喜的。

他真正想问的东西，要尖锐得多——

当AI能做数学的时候，数学家到底在做什么？

甚至，他还亮出了一道填空题，叫「AI能力猜想」。

在不远的将来的____之内，AI工具将以____的成本、在____程度的人类监督下，在____数学领域，完成____研究级数学任务，成功率____，正确性与质量____。


解题只是第一级台阶

这是陶哲轩这篇论文最硬核的一段。

他把「解一道数学题」这件事拆成了五级流水线，一级一级往上追问。你以为做到了就够了？远远不够。

第一级是解尽可能多的未解问题。

听起来合理，但如果只追求数量，会产生大量错误的解。一个什么题都往上冲的AI系统，和一个灌水的博士生本质没区别。

第二级是在此基础上加验证正确性。

好了一步，形式化证明工具可以让机器去检查每一步逻辑。

但对不对和好不好是两码事，一份正确但毫无洞见的证明，就像一篇没有语法错误但空洞无物的文章。

第三级是加上清晰表述，让人类能理解。

又进了一步，但这里出现了一个微妙的问题。

AI生成的证明往往「太光滑」了。每一步都逻辑严密，每个跳跃都被补齐，通篇没有一处让你困惑的地方。

听起来像优点？在数学家看来恰恰是缺陷。

人类写的证明有一种「自然摩擦」。作者会在关键处停下来解释为什么选这条路，会在困难处承认「这一步不显然」，会留下自己思考的痕迹。这些摩擦看起来像瑕疵，其实是给后来者留的路标。

打个比方，AI的证明像被传送到了山顶，人类的证明是带你爬上去，沿途告诉你这里有个坑，那边有条小路，远处那座山也值得看一眼。

第四级是被学术共同体消化接受。

这就更进一步了。发表在期刊上、通过同行评审，这些环节不是一个作者或者一台机器能优化的。审稿人有自己的判断，学术社区有自己的节奏。

第五级是最终融入学科的标准理论。

这是最高一级。一个结果被证明是一回事，被写进教科书是另一回事。经典化过程是整条流水线上最慢的环节，恰恰也是最有价值的。

五级台阶从下往上，越来越慢，越来越需要人。


数学要「消化不良」了

由此，陶哲轩提出了一个概念，可能是整篇论文里最锋利的贡献。

「证明消化不良」（proof indigestion）。

过去几百年，数学一直处于「证明稀缺」时代。难题太多，证明太少，每一个证明都金贵。

围绕数学建起来的整套基础设施，从期刊到评审到教学体系，全是为稀缺设计的。

现在，时代要翻过来了。

AI生成证明的速度，将远超人类验证、表述、评审、消化的速度。流水线入口被撕开了，但后面四级的处理能力没有变。

换句话说，数学的瓶颈，从「产生证明」变成了「消化证明」。

其实吧，上一次数学界这么焦虑，还要追溯到1920年代。那场「基础危机」撕裂了整个学科，希尔伯特和布劳威尔打得不可开交，争的只有一件事，数学的根基到底是什么。

一百年过去，根基的问题解决了。新的裂缝从完全不同的方向裂开。

陶哲轩的判断很直接，数学正面临一场堪比基础危机的新动荡。只不过这次动荡的核心，是数学研究的价值观和实践方式。

他在论文中用了一个巧妙的策略，提出了所谓的「工作假设」（Working Hypothesis）。

大意是，先别吵AI能不能做数学这件事了，暂时接受AI工具将在合理时间内完成相当比例的研究级数学任务这个假设，然后去追问一个完全正交的问题。

如果AI真能做数学，我们该怎么办？


讲不明白，就别发

面对这场风暴，陶哲轩给出了自己的原则，在ICM的演讲台上当着全世界数学家的面亮出来。

如果作者不能清晰讲解自己的成果，那就不该发表。即使形式化验证已经通过。

这句话，直接否定了一种正在蔓延的态度。AI帮我证了，Lean帮我验了，我虽然讲不太清楚每一步，但结果是对的，发吧。

陶哲轩说，不行。

但他也没有摆出那种「我不用AI」的清高姿态。他在演讲中坦率披露，自己使用AI进行文献搜索、文本自动补全和图表生成。

用AI没问题。但你必须站得上讲台，把每一步讲清楚。

2026年6月发布的《莱顿宣言》（Leiden Declaration on AI and Mathematics）也在说同一件事——

AI可以参与数学研究，但人类必须为最终成果负责。

回到费城那道填空题。

5年也好，50年也罢，空格里填什么数字根本不重要。陶哲轩真正留空的，是一个比时间表更根本的东西。

你做数学，到底图什么。

如果图的是把名字刻在定理上，这门生意的利润正在被AI迅速压薄。如果图的是理解这个世界为什么是这样运转的，那这件事从来就不是机器的活。

一百年前的基础危机催生了哥德尔、图灵、冯·诺依曼。危机没有毁灭数学。数学在回应危机的过程中，反而变得更深了。

Thurston说过一句话，放在今天听格外扎心。

我们不是定理的生产机器。证明的目的，是理解。

AI可以生产证明了。但理解这件事，暂时还没有任何机器能替人类完成。

陶哲轩把填空题留在了讲台上。那些空格等的不是一个数字，是整个学科对自己的重新回答。

3. 9亿人免费用，GPT私人秘书来了！

08-30 11:43 原文链接

新智元报道

ChatGPT 有 9 亿周活用户，付费的不到 5000 万，转化率只有 5% 到 6%。

8 月 26 日，OpenAI 把定时任务功能（侧栏的「已安排」）向所有免费用户开放。

这个此前只属于不到一成人的功能，一夜之间覆盖了剩余九成以上的用户。

定时任务让 ChatGPT 在后台按你设好的时间或条件自动跑一段提示词，跑完把结果推送给你。

你不在线，它也照跑。

对绝大多数免费用户来说，这是第一次不用打开对话框就能让 ChatGPT 替自己干活。

它能替你做什么

定时任务分三类，对应三种不同的使用场景。

最基础的是一次性提醒。

告诉 ChatGPT 一个时间和一件事，到点它推送给你。

比如：「包裹送到了告诉我一声。」

用得更多的是周期性任务。

每个工作日早上 7:30 推送一份 5 条以内的 AI 行业简报，限定领域、限定字数，等于一个零成本的定制晨报。

每周日上午列出下周的减脂食谱和采购清单，每晚 7 点给孩子生成一个新的睡前故事并配一张插图，这些都能用一句自然语言设定完成。

你可以把它当自己的外语私教：每天傍晚推送 5 个中等难度的英语句子，要求翻译，不给答案，等你回复后再批改。

第三类是监测型任务，也是最能体现「替你盯着」的一类。

你可以给 ChatGPT 贴一个商品页面的链接，让它盯住价格，比如跌破 1000 元就通知你。

同样的逻辑可以盯机票、盯房价、盯股价、盯 Steam 上某款游戏的折扣。

ChatGPT 会定期去查，没有变化时不打扰你，有值得报告的内容才推送。

做内容的人可以让它盯住竞品的产品页面或新闻发布，有更新了再来通知；

找工作的人可以让它盯住招聘网站上的特定职位，有新发布就推一条摘要过来。

8 月 26 日这批更新还加了一个更激进的能力：事件触发。

付费用户可以把 Gmail、Slack（国外的飞书）或 GitHub 接入 ChatGPT，让任务按事件跑。

客户在 Slack 频道（群组）里发了反馈，ChatGPT 自动总结要点并起草回复方案。

GitHub 上有人给你的 PR 提了 review，它会归纳修改意见列出修订计划。

邮件场景也一样：老板发来一封催进度的邮件，ChatGPT 读完后按你预设的模板起草回复。

从「每天早上 8 点查一次」到「有事才动」，这是定时轮询和事件驱动的区别。

前三类任务按时间跑，事件触发按条件跑，两者不能混在同一个任务里。

所有任务都在侧边栏的 Scheduled 页面统一管理，可以随时暂停、编辑或删除。

创建方式也简单：在对话框里用自然语言描述你想做什么、什么时候做，ChatGPT 确认后任务就开始了。

免费版的天花板在哪

OpenAI 给免费用户的配额很克制。

3 个活跃任务的上限，周期性任务每天最多跑一次，时间只能选「上午」「下午」或「晚上」这样的模糊时段，不能精确到几点几分。

付费用户的权限逐级递增。

Plus 用户（20 美元/月）可以建 5 个任务，支持精确到分钟的时间设定，最快每小时跑一次；

Business 和 Edu 用户上限 10 个；

Pro 和 Enterprise 用户上限 15 个。

8 月 25 日新增的事件触发功能（接入 Gmail、Slack、GitHub 的 webhook）只对 Plus 及以上套餐开放，免费用户和 Go 用户碰不到。

任务分享是这批更新里唯一不设门槛的功能。

一个用户配好的任务可以生成链接，另一个人打开后会得到一份独立的副本，可以改指令、改时间、接上自己的账号。

免费版拿到的相当于试用小样。

3 个任务够你设一个晨报、一个降价监测、一个睡前提醒，刚好够用，但没有余量。

想要精确控制和事件驱动，得加钱。

ChatGPT 的弯路与教训

定时任务其实不是一个新想法。

2025 年 1 月，ChatGPT 就上线过 Tasks 测试版，但功能简陋，用的人不多。

同年 9 月，OpenAI 换了一条路：推出 Pulse，一个只面向 200 美元/月 Pro 用户的主动推送功能。

拓展阅读：刚刚，ChatGPT Pulse上线！

Pulse 的逻辑是 AI 替你决定看什么——它根据你的聊天记录、记忆和已连接的应用，每天早上生成一组信息卡片，类似一份 AI 编辑的个人日报。

9 个月后，Pulse 被砍了。

2026 年 6 月 17 日，OpenAI 宣布 Pulse 在 14 天内下线，同时推出重建后的 Scheduled Tasks。

官方的总结是：「主动体验在个性化、可操作、用户可控的时候最有用。」

Pulse 替用户决定查什么，用户不买账；

Scheduled Tasks 反过来，让用户自己定义查什么、何时查。

6 月 17 日这次重建只对付费用户开放。

两个多月后的 8 月 26 日，免费用户才拿到入场资格。

同一天，事件触发能力上线——从 Tasks 测试版到今天，这个功能走了 20 个月，中间经历了一次大转向。

定时任务是 ChatGPT 从对话框走向后台常驻 Agent 的第一个大众入口。

但免费版 3 个任务、每天一次、模糊时段的配置，是 OpenAI 给出的试用小样——让你尝到「有人替你盯着」的甜头，然后为精确到分钟的控制力和事件驱动的自动化付费。

2. 丢给Claude一个活，它连你老板都记得！聊天干活记忆全打通

08-30 11:43 原文链接

新智元报道

你只是丢给它一个任务，它却连你老板都记得。

以后，把活儿交给Claude，不用再来一遍开场白了。

你在Chat里聊了三个月的项目：客户是谁、老板要什么、报告表格要排几列、哪个数字不能写进结论……

这些你在Chat里攒下的东西，等你把活儿交给Cowork时，它全记着。

Cowork干活时冒出来的新情况，也会原路带回Chat。

以前，Chat和Cowork就像是两个人。

Chat里那个跟你混熟了，Cowork里那个每次见面都得重新认识一遍：开场白从「我是谁、我们团队怎么算指标」讲起。

现在，聊天和干活之间这场冷启动，被取消了。

记忆开始从聊天框里的一个功能，转到了智能体干活时的上下文层。

8月25日，Anthropic正式宣布：Claude Chat和云端Claude Cowork，从今天起共用同一套记忆。

Claude记忆从此无处不在，而且，你能决定它记住什么。

Claude Code之父Boris Cherny转发了这条公告，称它是一个小改进：记忆现在更简单也更强了。

聊天说一次干活不用再讲

这次更新，放到日常场景，会更容易理解。

让Cowork给经理写一份工作更新，它知道经理是谁，也知道她想看什么样的写法。

在聊天框头脑风暴一场会议的议程，等Cowork去做预算和执行文档，人数、城市、讲者名单它都不用你再报一遍。

在Chat里讲清楚一次你们团队怎么定义指标，之后每一份季度经营回顾的材料，Cowork都按这套指标做，不需要重新交底。

而且，共享的记忆，会持续更新。

Cowork任务里冒出来的新上下文，会回流到Chat。

时间点也有意思。

8月18日，Cowork刚刚在网页端、桌面端和移动端对付费套餐铺开。7天后，记忆就打通了。

这次更新没往模型能力上使劲，改变的是它在开工前对你知道多少。

懂你，才能更好地为你干活。

记忆黑箱变成了随时可改的明账

看到「记忆打通」，很多人的第一反应是：我的聊天记录被搬走了。

不是这么回事。

官方帮助中心写得清楚：Claude存的是一组按话题生成的条目，叫Topics。

而且是边聊边存，不再像过去那样，等一段对话结束之后统一总结一遍。

差别在哪儿？

你随口提一句项目截止日期改到了9月，下一次开新对话，它就已经知道了，不用你专门交代，当然你不放心想多交代一句，让它记下来也可以。

更关键的，这些条目你能看见，也能修改。

打开Settings > Memory，Topics下面列着Claude记住的全部内容。点开任意一条能读，能改，也能删。

Memory设置页里的Topics列表，Claude记住的每一条都在这儿，可读可改可删。

因为这些文件都很短，你维护起来也很方便。

比如，公司改了名字，你去把那一条改掉，从此往后每一次对话都跟着改过来。

不想让它记了，有两个选项。

暂停，已有的记忆留着，但不再使用也不再新增，暂停期间的对话不会补记。重置，全部删光，包括项目记忆，点下去不可撤销。

而且，每个项目有自己独立的记忆空间和项目摘要，互不串门。

以前，AI记住了你的那些东西，你只能从它的回答里去猜。

现在它对你的认知，成了设置页里一份你随时可以动手编辑的文档。

记忆功能，从黑箱变成了随时可改的明账。

记忆的三层开关

这次的一个重磅设计，是Anthropic给记忆划了三层开关。

第一层，默认存。

你的角色、项目、工作和生活里的人和地方、沟通偏好、技术偏好、代码风格、手上正在推进的事……这一层通常包括日常协作需要的那些上下文。

第二层，默认不存，但你可以自己开。

健康、种族、族裔、宗教信仰、性别认同这一类。

官方的说法是，有些人觉得敏感，有些人觉得有用。

比如，开了这个开关，Claude给你排一周备餐的时候，会记着你麸质过敏。

这个开关，背后是三条细则。

只对开启之后的内容生效，之前的不追溯。

每存一条这类内容，输入框上方都会跳出一条提示，你能当场复查或者改设置。

如果你拒绝了提示，或者后来把开关关掉，已经存进去的敏感条目会被清掉。

第三层，永不存。

证件号码、犯罪记录、金融账户号码、移民身份，以及任何违反使用政策的内容。

这一层不带开关。

就算你主动要求Claude记下来，它也不会存，还会明确告诉你为什么存不了。

Chat和Cowork打通了吗？

不全是，打通的是云端的Cowork。

官方在博客和帮助中心两处写了同一句话：这套共享记忆只在Cowork跑在云端的时候生效。

不包括跑在你自己电脑上的本地会话。

免费用户也能用上统一记忆工作流吗？

不能。

免费、Pro、Max三档默认开启的是Claude的记忆，不是Cowork。

Cowork仍然只对Pro、Max、Team、Enterprise开放。

不同的终端，情形也不同。

macOS和Windows桌面端对全部付费套餐开放，网页端和移动端是Pro、Max、Team，Enterprise要看管理员有没有开。

Team和Enterprise默认是关的，得由组织所有者在设置里开。

这里还藏着一颗雷：所有者一旦把组织级记忆关掉，全组织所有人的记忆条目会立刻被永久删除。

另外，签了HIPAA、公共部门或者部分自定义数据留存协议的组织，暂时用不了记忆。

对话过期或者被删除，由它生成的记忆条目不会跟着删。

想清掉，得去Settings > Memory里单独删。

这一条大概是普通用户最该知道，也最容易漏掉的。

打通之后，还能跟Claude聊敏感话题吗？

照聊。

默认关掉的只是「写进长期记忆」这个动作，不是聊天本身。

你想聊健康，Claude一句不落地陪你聊，只是聊完不往记忆里存。

下一轮竞争比的是谁不用重新认识你

Cowork是什么？

官方的定义是：把Claude Code那套智能体架构搬到编程之外的知识工作上，不需要终端。

它能拆任务，能并行调度子智能体，能在云端一直跑，你合上笔记本它照跑，还能设成定时任务，电脑不开机也执行。

现在，再给它接上一整套已经攒了几个月的上下文。

这个小改进背后，藏着一个新变化。

模型能力可以追平，今天你领先两个月，明天对手就补上来。但用户攒下的上下文很难追平。

一个已经知道你怎么写周报、你们团队怎么算指标、你上个季度跟谁打过交道的系统，换掉它的代价不是那点订阅费，是你得把自己重新讲一遍。

有意思的是，Anthropic把门留着了。

官方支持在Claude和其他AI服务之间导入导出记忆，虽然还标着实验阶段。门开着，赌的是你不会走，别人会来。

上一轮智能体竞争，大家抢的是任务：谁能把活干完，谁能干得更久。

下一轮竞争的东西变了：是你的记忆，你不想再解释第二遍的那些事，最后存在谁家。

一个是3D像素风格的城堡，另一个是前端网页，全部都是一次直出。

与此同时，一大批拿到灰度资格的开发者们，同一时间放出了Astra首批测试。

  • 前端非常强大，0样本一次生成

要知道，前端一直是大模型的老大难。

后端逻辑写得再溜，一到生成UI就露馅，比如，臃肿的CSS、辣眼的配色....

开启最大思考程度，Astra可以做到一次成型。

在Max模式下，Astra模型往往比Sol思考得更多，但从下面的输出可以看出，它对细节的关注度极高。

永久智能体四大技术内核扒光

为什么Astra的前端能力会，一夜之间脱胎换骨？

首先是，端到端多智能体编排。

Astra可能不再是一个单纯的「单体代码生成器」，而在底层原生集成了多智能体架构。

这跟GPT-5.6中已经以beta形态推出的Multi-agent功能一脉相承，但Astra可能将其内化为「端到端训练」的原生能力。

这对代码项目的持续开发、论文级别的研究任务、以及复杂工作流的自主执行都意义重大。

第三，持久化推理模式（Persistent' Reasoning）。

Astra在Max effort下的思考量显著超过Sol，这指向一种更「持久」的推理机制。

模型不会一次性输出答案，而在内部反复验证、纠错、迭代，直到输出达到满意水平。

这意味着它能「记住」当前DOM树的结构，在后续生成中保持设计语言和代码规范的绝对一致。

第四，即时自我纠错。

这是最可怕的一点，Astra可能在生成代码的同时，在内部沙盒中完成了「虚拟渲染」或AST语法树的逻辑跑通。
